# The 25 Newest MCP Servers on the Swarms Marketplace: Official Servers from Google, PayPal, Neon, Perplexity and More

On October 20, 2026 the [MCP marketplace on swarms.world](https://swarms.world/mcp-servers) gained 25 new servers in a single drop. Every one of them is an official, vendor-hosted Model Context Protocol server: the endpoint the company itself runs, not a community wrapper around its API. Together they cover databases and analytics, payments, web search and scraping, infrastructure and hosting, project management, design, voice, enterprise content and customer support.

All 25 were published by one marketplace user, [mcp_depot](https://swarms.world/users/mcp_depot). Below is each server in the order it was published, newest first, with its listing on the marketplace. Every listing carries a **Connect to this MCP server** section with the server URL, its auth and transport badges, its tools, and copy-paste configs for Claude, Cursor, VS Code and other MCP clients, so any of these is a minute away from being in your agent's toolbox.

## Publish your own MCP server for free

If you run an MCP server, it belongs on the same page. Publishing is free and takes three steps:

1. Go to [swarms.world/launch](https://swarms.world/launch) and open the **MCP URL** tab.
2. Paste your server URL and click **Inspect**. The marketplace connects to your server, reads its tools, detects how it authenticates and fills in the listing for you.
3. Click publish. Your server appears on the [MCP servers page](https://swarms.world/mcp-servers) with the same connect section, client configs and one-click installs as the 25 above.

You can keep access free or set a price, and the [Seller Portal](/blog/swarms-seller-portal) tracks everything you earn. The [expanded MCP support post](/blog/expanded-mcp-support-swarms-marketplace) covers the inspector and the auth options in detail.
