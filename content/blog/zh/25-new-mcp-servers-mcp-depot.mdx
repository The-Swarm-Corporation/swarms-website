# Swarms Marketplace 最新上架的 25 个 MCP 服务器：来自 Google、PayPal、Neon、Perplexity 等厂商的官方服务器

2026 年 10 月 20 日，[swarms.world 的 MCP 市场](https://swarms.world/mcp-servers)一次性新增了 25 个服务器。每一个都是官方的、由厂商自己托管的 Model Context Protocol 服务器：由公司本身运营的端点，而不是社区对其 API 的二次封装。它们覆盖数据库与分析、支付、网页搜索与抓取、基础设施与托管、项目管理、设计、语音、企业内容以及客户支持。

这 25 个全部由同一位市场用户 [mcp_depot](https://swarms.world/users/mcp_depot) 发布。下面按发布顺序（最新在前）逐一介绍每个服务器，并附上它在市场上的商品页。每个商品页都带有 **Connect to this MCP server** 区块，包含服务器 URL、认证与传输方式徽标、工具列表，以及可直接粘贴到 Claude、Cursor、VS Code 和其他 MCP 客户端的配置，所以任何一个都只需一分钟就能进入你的智能体工具箱。
