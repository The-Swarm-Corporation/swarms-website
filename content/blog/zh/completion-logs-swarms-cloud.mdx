# Swarms Cloud 推出调用日志

可观测性迎来一次大幅升级。

现在，发往 Swarms API 的每一次请求都汇总在同一个地方。你可以按智能体名称或 ID 搜索和筛选，监控 token 用量与成本，并查看完整的请求负载和输出结果。

理解、调试、优化 Swarms 工作流所需的一切，现在都在 [cloud.swarms.world/history](https://cloud.swarms.world/history)。

![Swarms Cloud 的执行历史页面：账户发出的每一次 API 请求，附带搜索、日期筛选，以及每次运行的 token 用量与成本](/api_logs.png)

## 所有请求，汇于一处

执行历史页面读取的是你账户自己的请求日志。API 密钥发出的每一次调用都在这里：单智能体、多智能体集群、图工作流、批量网格、自动智能体构建器的运行记录。每一次调用对应一行。

一行记录会告诉你：这次运行是否成功、由哪个智能体或端点处理、收到的任务是什么、消耗了多少 token、花了多少钱、发生在什么时候。这些字段都可以排序。按 token 降序可以找出开销大的运行，按成本降序则能优先看到最值得关注的那些。

**搜索不止匹配名称。** 在搜索框里输入内容，它会匹配智能体名称、端点、请求 ID、时间戳和任务文本，然后继续深入原始日志正文。只要某个字符串在请求或响应中出现过，就能定位到承载它的那次运行，而这通常正是你查找出错调用的方式。

**日期筛选作用于全局。** 最近 24 小时、最近 7 天、最近 30 天，或者自定义起止日期的区间。页头的计数会随筛选实时更新，你始终清楚自己正在查看多少历史记录。

## 每一次调用都有独立页面

这一点改变了整个页面的用法。点击某一行不再是就地展开，而是在独立页面上打开这次调用。

也就是说，账户里的每一次运行现在都有了自己的 URL。你可以在缺陷报告里链接到某次失败的调用，收藏一次用作对照的运行，在三个标签页里同时打开三次运行，或者把确切的调用记录直接发给同事，而不是描述该怎么找到它。

页面开头是这次运行的身份信息：它以哪个智能体的身份运行、带复制按钮的调用 ID，以及成功还是失败。下面是这次运行本身的一组数字：发生时间、输入 token、输出 token、token 总量，以及成本。

再往下是列表视图始终无法很好呈现的两样东西：

**可跳转的智能体。** 调用页面上的智能体名称直接链接到该智能体自己的页面，系统提示词、完整配置、以及它在所有运行中的累计成本都在那里。从一次可疑的运行追溯到产生它的配置，现在只需要一次点击。

**作业 ID。** 它从请求负载中提取出来，单独成行并配有复制按钮，因为当你联系支持团队或者与自己的日志做关联时，这正是最关键的标识符。

## 完整的请求与响应

页面下方才是调用详情页真正值得打开的部分：提交时的确切请求负载，以及返回的确切响应，两者都以格式化 JSON 呈现。

不是它们的摘要，而是真实的对象，包含 API 接收和返回的每一个字段。如果某个智能体的行为出乎你的意料，答案几乎总在里面：系统提示词和你以为的不一样、temperature 还停留在默认值、模型名称悄悄回退了、某个工具定义根本没有进入这次调用。

两个面板在页面上都有充足的展示空间，遇到较长的负载时，任意一个都可以展开为全屏视图。过长的内容会自动换行，而不是消失在右侧边缘之外，因此几千字符的提示词是可读的，不需要横向滚动。

每个调用页面的页头还有一个 **Download JSON** 按钮。点击一次即可把整条日志，包括请求和响应，保存为以调用 ID 命名的 `.json` 文件。你可以把它附在 issue 里，对比两次运行的差异，或者交给你惯用的分析工具。

## 真正准确的成本

有一处细节值得单独说明，因为它此前一直是错的，现在在各处都已修正。

Swarms API 会根据产生运行的端点不同，把这次运行的费用放在不同的字段下。智能体调用使用 `total_cost`，图工作流、批量网格工作流和自动智能体构建器使用 `token_cost`，集群调用则把它嵌套在 `billing_info` 里。只读取其中第一个字段是最直觉的做法，但那样大多数运行类型都会显示为 `$0.00`。

历史页面、调用详情页以及 CSV 导出中的每一个成本数字，现在都经由同一份共享定义计算，而它认得上述三种情况。你看到的总额，就是你实际支付的总额。

## 把数据带走

筛选后的日志可以导出为 CSV。当前应用的搜索条件和日期区间是什么，文件里就是什么：时间戳、智能体名称、端点、ID、状态、任务、输入 token、输出 token、token 总量，以及每次运行的成本。

这覆盖了浏览器并不擅长的那类报表工作，比如按智能体统计月度成本、观察一个季度的 token 增长、按端点计算成功率。导出所需区间，然后在你惯用的工具里做透视分析。

## 在哪里找到它

打开 [cloud.swarms.world/history](https://cloud.swarms.world/history)。页面上的一切都通过 `/v1/account/logs` 从你自己的账户读取，无需事先启用、埋点或配置。你的历史记录已经在那里了，包括这次功能上线之前的运行。

如果你从未查看过它，可以先按成本降序排序，然后打开第一行。大多数账户都会在最初的三十秒里发现一些出乎意料的东西。
