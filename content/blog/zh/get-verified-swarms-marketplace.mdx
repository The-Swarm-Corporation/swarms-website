# 在 Swarms Marketplace 上获得认证

[Swarms Marketplace](https://swarms.world) 现已推出 **Verified**（已认证）徽章。每位 Pro 和 Premium 会员都会在公开个人主页的用户名旁获得一枚带对勾的蓝色徽章，只要套餐处于有效状态，徽章就会一直显示。

无需提交申请，也无需排队审核。订阅每月 19.99 美元的 Pro，或选择 Premium，付款完成后徽章就会立即出现在你的个人主页上。

本文将介绍徽章代表什么、买家在哪里能看到它、它如何授予和取消、Pro 与 Premium 包含哪些内容，以及如果你在市场上发布或销售产品，为什么值得开启它。

## 徽章的含义

Verified 徽章只代表一件事：**该账户拥有有效的 Pro 或 Premium 套餐。**

我们希望把这一点说清楚，因为“认证”在不同平台上含义各不相同。这枚徽章不验证你的身份，也不评价你的智能体、提示词或工具的质量。它告诉买家：这个主页背后的人付费使用平台，并且仍在活跃。在一个几秒钟就能注册新账户的市场里，这是一个有用的信号，买家一眼就能看懂。

## 买家在哪里看到它

徽章位于你公开个人主页 `swarms.world/users/<你的用户名>` 顶部的用户名旁边。买家在商品页面上点击你的名字后就会来到这个页面，也正是在这里，他们决定是否把钱或 API 密钥托付给你。

徽章是一个蓝底白字的标签，带有白色对勾和 **Verified** 字样，紧跟在你的 `@用户名` 之后，位于显示名称和简介上方，是访客在你名字之后看到的第一样东西。

点击徽章会打开 [swarms.world/verified](https://swarms.world/verified)，任何想了解徽章含义的访客都可以在这里找到答案，并为自己开通。

## 如何获得认证

1. **打开订阅标签页。** 前往 swarms.world 上的[账户页面](https://swarms.world/platform/account?tab=subscription)，打开 Subscription（订阅）标签页。
2. **选择 Pro 或 Premium。** 两个套餐都包含徽章，区别在于 Swarms API 的功能，详见下文。
3. **使用银行卡或 USDC 付款。** 银行卡付款通过 Stripe 处理；USDC 从你的 Solana 钱包支付。
4. **查看你的个人主页。** 付款完成后，徽章就会显示在你的个人主页上。

整个流程就是这样。无需填写表单，无需上传文件，也无需等待任何人。

## 工作原理

徽章与你的订阅直接绑定。系统中不存在需要人工设置、或需要有人记得去移除的单独“认证”标记。

渲染你的个人主页时，服务器会读取你的订阅信息，判断你是否属于已认证用户：

- **银行卡订阅（Stripe）**：只要订阅在付费套餐上处于有效状态即计入。这与平台设置账户等级所用的规则相同。
- **USDC 订阅**：在你已付费的周期（月付或年付）结束前一直计入。每笔付款在延长周期之前，都会在链上与 Swarms 金库进行核对。

你的账单信息保持私密。订阅查询在服务器端完成，传到浏览器的只有一个“是”或“否”：已认证或未认证。访问你主页的人永远看不到你使用哪个套餐、如何付款或何时续费。

### 取消订阅后会怎样

取消订阅不会立即移除徽章。徽章会保留到你已付费周期结束，然后自动消失。如果之后重新订阅，新付款完成后徽章就会恢复。如果银行卡续费失败，在订阅处于未付款状态期间徽章会暂时消失，付款成功后再恢复。

## 为什么市场创作者应该获得认证

如果你在市场上发布智能体、提示词、工具、MCP 服务器或捆绑包，每当有人查看你的个人主页，这枚徽章都在为你发挥作用。

### 买家能把你和临时账户区分开

一位在两个相似智能体之间做选择的买家，能参考的信息很少：标题、描述、评分，以及创作者的个人主页。带有 Verified 徽章的主页属于一位付费使用平台的人；一个没有徽章的新账户可能属于任何人。当其他条件相差无几时，这个差别往往决定了哪一个被买走。

对于智能体类产品，这一点比大多数数字商品更重要。智能体或提示词常常会使用买家的 API 密钥、shell 或数据访问权限运行。人们对把这些托付给谁非常谨慎，付款前会寻找可信的信号。

### 更多人能发现你的产品

Pro 和 Premium 会员的产品会在整个市场中被推荐给其他用户。在热闹的市场里，被发现是销售任何东西最难的一环，而推荐能把你的商品展示给那些并没有按名字搜索你的买家。

### 更高的速率限制，便于构建与测试

大多数市场创作者也在使用 [Swarms API](https://docs.swarms.ai) 进行构建。Pro 和 Premium 会提高你的 API 速率限制，Premium 更是将其翻倍，让你在测试智能体、运行评估以及服务自己的用户时，不会撞上免费版的上限。

### 费用大约相当于一笔销售

Pro 每月 19.99 美元，大约相当于一次智能体或提示词的销售额。套餐中的其他权益，从更快的硬件到遥测平台，都是额外收获。

### 徽章状态始终自动保持准确

由于徽章跟随你的订阅，你永远不需要申请、续期认证或再次证明任何事情。它始终是准确的：套餐有效时显示，套餐结束时消失。

## 常见问题

**免费套餐包含徽章吗？**
不包含。徽章仅随 Pro 和 Premium 提供。

**Verified 是否意味着 Swarms 核实了我的身份？**
不是。它表示该账户拥有有效的 Pro 或 Premium 套餐。它不是身份核验，也不对你的产品进行评级。

**使用 USDC 订阅可以获得徽章吗？**
可以。从 Solana 钱包支付的 USDC 订阅与银行卡订阅完全一样计入，直到你已付费的周期结束。

**徽章多快会出现？**
付款完成后立即出现。打开 `swarms.world/users/<你的用户名>` 即可查看。

**其他人能看到我的套餐或账单信息吗？**
不能。你的个人主页只知道你是否已认证。你的套餐、付款方式和续费日期都保持私密。

**从 Pro 升级到 Premium 会怎样？**
徽章会一直保留，两个套餐都包含它。
