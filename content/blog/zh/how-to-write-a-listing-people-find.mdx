# 如何写出真正能被找到的商品页

[Swarms Marketplace](https://swarms.world) 上已经有超过 6,000 个智能体、提示词、工具和 MCP 服务器。一个发布了却没人找到的商品什么也赚不到，而“被找到”与“被埋没”之间的差别，往往就取决于[发布页](https://swarms.world/launch)上的几个字段：标题、标签、描述的第一句话，以及页面是否展示了产品实际能做什么。

本指南逐一讲解这些字段，适用于所有产品类型，依据的是 Swarms Marketplace 今天的搜索与发现机制。如果你是第一次发布提示词，可以搭配阅读[十分钟发布你的第一个提示词](/blog/publish-your-first-prompt)，那篇文章讲的是表单本身的操作。

## 先了解人们如何搜索

下面的每一条建议，都源自商品被找到的几种途径。

- **注册表搜索框**位于 [swarms.world/platform/registry](https://swarms.world/platform/registry)，会同时匹配你的名称、描述和标签。它的占位文字就是这么写的：“Search by name, description, or tags...”。
- **导航栏搜索**出现在每个页面上，排序时精确名称匹配优先，其次是前缀匹配，最后才是其他结果。
- **筛选栏**可以按商品类型、定价、自由输入的标签（不区分大小写的子串匹配）和行业来缩小范围。行业列表与你发布时选择的分类列表是同一份。
- **[Autonomous Filter Search](/blog/autonomous-filter-search-agent)**，也就是注册表搜索框旁的 AI 按钮，会把一句自然语言请求翻译成上述筛选条件。它每小时都会从真实商品上最常见的 100 个标签中刷新自己的词表，所以只会把请求映射到确实存在的标签上。
- **[Swarms Marketplace MCP](/blog/swarms-marketplace-mcp-server)** 位于 `swarms.world/mcp`，让其他智能体可以按名称、标签、分类、语言、所需软件包、用例或价格来搜索。

写名称、标签和描述时，请面向一个正在用自己的话输入需求的读者。

## 标题

名称是搜索中权重最高的字段，也是买家在卡片上唯一一定会看到的文字。

**先写任务，再写领域。** 把买家会输入的名词放在最前面：“Clinical Trial Protocol Reviewer”、“Shopify Order Reconciliation Agent”。导航栏搜索中精确匹配和前缀匹配排在最前，所以第一个词最重要。

**短到能放进卡片。** 网格卡片和表格行都会截断过长的文字。三到七个词是比较合适的范围。

**避免泛泛的名字。** “AI Assistant”和“Research Agent”要和成百上千个同名商品竞争，而且什么信息都没传递给买家。

**不要以“x402”开头。** 名称以“x402”开头的智能体默认会被排到注册表每一页列表的末尾，不管筛选条件和排序方式如何，买家还可以把它们整体排除。版本号、表情符号和全大写会浪费卡片本就有限的字符，也匹配不到任何人搜索的内容。

| 弱标题 | 问题所在 | 更强的标题 |
| --- | --- | --- |
| AI Research Agent | 成百上千个同名商品，没有领域 | Biotech Patent Prior-Art Researcher |
| My Awesome Prompt v2 | 对任务只字未提，版本号是噪音 | Cold Email Sequence Writer for B2B SaaS |
| x402 Super Trading Bot 🚀 | x402 前缀会被排到末尾，表情符号浪费空间 | Perpetuals Funding Rate Arbitrage Agent |
| Firecrawl Thing | 含糊，无法按能力搜索到 | Firecrawl MCP: Web Search, Crawl, and Scrape |

## 标签与分类

标签决定了标签筛选、注册表搜索和 Autonomous Filter Search 智能体能否找到你。分类决定了行业筛选和 MCP 服务器页面能否找到你。两者都要设置。

**用买家描述需求的方式写标签。** 买家会输入“customer support”、“lead-gen”或“pdf-extraction”，所以你的标签应该就是这些短语的 kebab-case 形式，大约五到十六个。发布表单上的标签生成器会根据你的名称和描述给出一组建议，它会拒绝 `ai`、`tool`、`helper`、`useful` 这类填充词，并且混合三类标签：行业（`healthcare`、`fintech`）、类型（`research-agent`、`mcp-server`）和能力（`web-scraping`、`sql-generation`）。以它为起点，再加上你知道买家真正会用的词。

**对齐目录里已有的词汇。** 像 `trading` 这样的常见标签能把你连接到每一次交易相关的搜索；像 `my-quant-system` 这样的独创标签什么也连接不到。注册表的表格视图里每个标签都可以点击，所以不妨复用最强竞品带的标签，再加上让你与众不同的那几个。

**选择买家会用来筛选的分类。** 目录大约有二十个分类，包括 Finance、Research、Developer、Security、Healthcare、Marketing、Sales、Customer Support 和 MCP。如果你的产品符合两个分类，就两个都选。带有 MCP 服务器 URL 发布的智能体会自动获得 MCP 分类，并出现在 [swarms.world/mcp-servers](https://swarms.world/mcp-servers)；以工具或提示词形式发布的代码型 MCP 服务器，则需要手动勾选 MCP 分类。

## 描述

描述同时是搜索文本、卡片文本和销售页。请按这个顺序来组织它。

**第一句：搜索摘要。** 卡片和表格行显示的是截断后的描述，而注册表搜索匹配的是全文。把第一句写成一个完整的陈述，说明产品做什么、为谁而做，并使用买家会搜索的词：“审查供应商合同中的 GDPR 与 SOC 2 条款，返回带引用的风险表，面向 B2B 软件公司的合规团队。”

**第二段：输入与输出。** 对智能体而言，是它期望的输入（一个 URL、一个 CSV、一个问题）和输出格式（一份 markdown 报告、JSON、一张表）。对提示词而言，是用户粘贴进去什么、模型返回什么。对工具而言，是用通俗语言说明的函数。对 MCP 服务器而言，Swarms Marketplace 会从你的服务器读取工具并替你列出来（参见[扩展的 MCP 支持](/blog/expanded-mcp-support-swarms-marketplace)），所以把篇幅花在这些工具合起来能完成什么任务上。

**第三段：运行要求。** 它基于哪个模型构建和测试、需要哪些 API 密钥或环境变量、有哪些软件包依赖，以及智能体会触碰什么（shell、网络、钱包）。用自己的密钥运行智能体的买家，付款前一定会找这些信息。审核每一份提交的发布评审智能体也会通读全文寻找这类实质内容：免费商品需要 5 分制中 2.5 分才能发布，付费商品需要 3.5 分。

**然后是用例。** 发布表单的 Use Cases 区域为每个用例提供标题和一段简短描述。填两到三个真实的用例；Swarms Marketplace MCP 允许智能体按用例搜索商品。

如果你检测过一个 MCP 服务器，Swarms Marketplace 根据服务器元数据替你填好了名称和描述，请用自己的话重写它们。文字保持平实：每个商品页的 Summary 标签页会把整页浓缩成两到四句话，一段具体说明产品做什么的描述才能被很好地概括。

## 展示真实输出

付款之前，买家能看到你的图片、描述、评分、点赞数和购买数。付费提示词或智能体的正文在购买完成前是隐藏的，所以页面公开部分最有力的东西，就是一份产品实际产出的样例。

- **提示词：**一段简短的对话，包括用户输入和模型回复，裁剪到能体现质量的部分。
- **智能体：**一次节选的运行记录，包括你交给它的任务和输出的第一屏。如果它返回结构化数据，就展示真实的 JSON 或表格，敏感值做省略处理。
- **工具：**一次调用及其返回值。
- **MCP 服务器：**连接区域已经列出了你的工具、参数以及只读或破坏性标记。再补一段文字，描述智能体用这些工具完成的一个任务。

把样例放进代码块中，标注为示例，并标明所有节选之处。

**设置图片。** 没有图片的商品会显示占位图；有图片的商品会在卡片和页面上获得一张 16:9 的主图，发布表单的图片生成器可以根据你的名称和描述生成两张横幅供选择。

## Verified 徽章与 Security Score

Swarms Marketplace 上有两个信任信号是你可以掌控的。

**Verified。** Pro（每月 19.99 美元）和 Premium 会员会在个人主页 `swarms.world/users/<your-username>` 的 `@username` 旁获得一个蓝色 **Verified** 标签。买家点击商品页上你的名字后落到的就是这个页面，他们在这里决定是否愿意把钱或 API 密钥托付给你。这个徽章的含义是账户拥有有效的付费套餐；它不是身份验证，也不对你的产品做评价。参见[在 Swarms Marketplace 获得 Verified 认证](/blog/get-verified-swarms-marketplace)。

**Security Score。** 每个提示词页面都有一个 **Security** 标签页，扫描完成后，页面横幅上会出现一个 `Security Score: N` 标签，紧挨着 FRENZY、VAULTED 之类的标签。分数范围是 0 到 100，越高越安全，80 分及以上显示绿色盾牌，低于 80 分显示红色盾牌。分数来自 [SkillScanner](https://github.com/The-Swarm-Corporation/SkillScanner)，由 49 条确定性规则加一次智能体评审得出。详情见[每个提示词现在都有 Security Score](/blog/prompt-security-scores-swarms-marketplace)。

有两点会改变你的发布方式。第一，**买家看到的是第一次完整扫描的结果**：之后编辑提示词不会触发重新扫描，所以请在发布前先扫描。第二，**诚实的提示词里，大多数问题都来自几个习惯**：“忽略之前的指令”或“不要告诉用户”、短链接或明文 `http://` 链接、写在文本里的 API 密钥、藏在 HTML 注释或 base64 里的指令，以及没有说明理由的 shell 或网络访问。公开说明提示词做什么，链接用 HTTPS 完整写出，不放任何密钥，并在提示词里解释所有敏感行为。

SkillScanner 是开源的，可以在本地用 `scanner.scan_text()` 扫描你的提示词文件，所以绿色分数是在任何人看到商品页之前就能拿到的。

## 商品是如何被展示的

Swarms Marketplace 没有公布排名公式，所以请从可见的信号出发。

- **Newest First 是注册表的默认排序。** 每个商品发布时都会在未筛选的注册表顶部停留一段时间。[Explorer](/blog/swarms-marketplace-explorer) 的 24 小时发布卡片会显示你当天要和多少个商品竞争。
- **Most Popular 要求至少两个点赞。** 它在排名前会过滤掉不足两个点赞的商品；Most Upvoted 则没有门槛。来自真实用户的两个早期点赞，就能把商品从一个列表移到另一个列表。
- **评分和评价是公开的。** 发布评审智能体会把它的评估作为一条评价写进你的商品页，买家评分随后加入，你的个人主页则显示平均评分。
- **精选行是人工策划的。** MCP 服务器页面有一行手工挑选的精选，首页有一个精选轮播。完整、带真实示例输出的商品页才会被选中。
- **推荐面向付费套餐。** Pro 和 Premium 会员的产品会在整个 Swarms Marketplace 中被推荐给其他用户。
- **代币化产品**有 [Screener](https://swarms.world/screener)，它按最新发布排列，并按市值排出一条趋势栏。

筛选本身是确定性的：标签、分类和定价标记都正确的商品，会出现在每一个描述它的筛选组合里。

## 定价呈现

买家会按价格筛选，卡片也会显示价格，所以定价是文案的一部分。

- **Free 或 Paid 是一个筛选条件。** 注册表可以显示或排除 Free、Paid、Tokenized、Vault 和 Frenzy 商品。无论你选哪一个，都意味着进入一组搜索，同时退出另一组。
- **付费商品在卡片上显示美元价格**并带有付费标记，买家点开之前就能看到价格。在描述第一句里说明这个价格买到的是什么，并说明是一次性付费：来自其他平台的买家不被告知的话会默认是订阅。
- **按商品选择收款渠道。** 付费商品以 Crypto (SOL) 或 Card / Fiat (Stripe) 收款；在 Stripe 报告你的账户已激活之前，发布页会阻止发布以银行卡定价的商品。买家一次付费，获得永久访问权。代币化发布始终以加密货币结算。参见[如何销售你的智能体和提示词](/blog/how-to-sell-agents-prompts-stripe-crypto)。
- **免费是一种策略。** 免费提示词任何人都能完整阅读，包括通过 MCP 读取目录的智能体，而一个优秀的免费商品积累的评分和点赞，会通过你的个人主页惠及你的付费商品。

## 保持商品页的新鲜度

[Seller Portal](https://swarms.world/platform/seller) 是维护已发布商品的地方。

**阅读评价与评论信息流。** 它把你所有商品上的每条评价和评论集中到一处。评论里的一个买家提问就是一笔等着答复的订单，而且有人评论或点赞时你会收到邮件。

**在产品页上编辑。** 点击 Seller Portal 表格中的任意商品即可打开并编辑它。当你更换模型、新增依赖，或者弄清楚买家会搜索哪些措辞时，就更新描述。编辑提示词不会触发重新扫描，所以重大修订请自己扫描。MCP 商品页会自行刷新：当商品页被查看且上次检查距今超过一天时，Swarms Marketplace 会重新检测你的服务器。

**每次改动后观察 90 天收入图表。** 新标题、新图片或新标签组合，几天内就会体现在柱状图里。

## 发布前检查清单

- **标题**以任务开头，点明领域，能放进卡片，不以“x402”开头。
- **标签**：五到十六个 kebab-case 词条，混合行业、类型和能力，对齐已有标签，没有填充词。
- **分类**：买家会用来筛选的每一个行业，代码型 MCP 服务器加上 MCP。
- **第一句话**用搜索用语说明它做什么、为谁而做。
- **输入、输出、运行要求**已列出：模型、密钥、依赖、会触碰什么。
- **用例**：两到三个真实用例。
- **示例输出**放在代码块中，已标注，节选处已标明。
- **图片**已设置，16:9，画面中没有文字。
- **Security Score**已用 SkillScanner 检查（提示词），问题已修复，达到 80 分或以上。
- **定价**：有意识地选择 Free 或 Paid，选好收款渠道，用银行卡则 Stripe 已激活，一次性价格已说明。
- **个人主页**：用户名和简介已填写，如果你卖东西，Verified 已开启。
- **实时预览**：以买家的视角读一遍发布表单上的预览。

发布后，打开注册表并点击 Refresh，确认商品已上线。然后让 Seller Portal 保持打开，等第一条评论到来。
