# MCP Portal 正式上线：在 Swarms Marketplace 上发现、发布并变现 MCP 服务器

MCP 生态从这里开始。我们在 [Swarms Marketplace](https://swarms.world) 上推出了 [MCP Portal](https://swarms.world/mcp)，一个专门用于发现、探索和发布 Model Context Protocol（MCP）服务器的家园。在这里，你可以找到最受欢迎的 MCP，把智能体接入真实工具，并让自己的 MCP 服务器产生收入，一站式完成。

## 什么是 MCP 服务器？

MCP 服务器是实现了 [Model Context Protocol](https://modelcontextprotocol.io) 的服务。MCP 是一项开放标准，让 AI 智能体能够通过一个统一接口调用真实工具：网络搜索、网页抓取、数据库、文件系统、GitHub、语音，以及任意 API。

在 MCP 出现之前，把智能体接入一个新工具，意味着要为每个工具和每个框架编写定制的集成代码，而且任何一方发生变化都得重写。MCP 用一份标准契约取代了这一切：任何兼容 MCP 的智能体，都能立即使用任何 MCP 服务器。集成只需编写一次，就能在协议覆盖的所有地方运行。

正是这种标准化，让 MCP 迅速成为 AI 智能体与真实世界之间的默认接口，也是我们为它专门打造一个门户的原因。

## MCP Portal 提供什么

[MCP Portal](https://swarms.world/mcp) 是覆盖 MCP 全生命周期的单一入口：

- **浏览最受欢迎的社区 MCP 服务器**，经过排名与精选，最好的工具最先呈现
- **按能力发现工具**：网络搜索、抓取与爬取、编程、GitHub 与文档研究、语音、API 等等
- **通过标准化协议将任意 MCP 服务器接入你的 AI 智能体**，每个商品页在连接前都会展示价格
- **发布你自己的 MCP 服务器**，可选择免费或付费
- **探索每周精选的 MCP 服务器**，由 Swarms 社区亲自挑选
- **一个统一的市场**，完成 MCP 的发现、分享与变现：不需要分散的注册表，也不需要在 GitHub readme 之间来回翻找

门户上的所有内容也会出现在[完整注册表](https://swarms.world/platform/registry?type=agents&industry=mcp)中，你可以在整个目录范围内筛选、排序和搜索。

## 如何将 MCP 服务器接入你的 AI 智能体

接入只需几分钟：

1. **找到一个服务器**：在 [MCP Portal](https://swarms.world/mcp) 上浏览精选推荐，或搜索完整目录。
2. **打开商品页**，查看该服务器提供哪些工具、它的文档和价格（许多是免费的；付费服务器会在连接前展示价格）。
3. **将它接入你的智能体。** 连接完成后，你的智能体就能通过标准协议调用该 MCP 服务器提供的所有工具，无需任何定制集成代码。

由于 MCP 是开放标准，市场上的服务器可以与任何兼容 MCP 的智能体框架配合使用，包括基于 [Swarms](https://docs.swarms.ai) 构建的智能体。
