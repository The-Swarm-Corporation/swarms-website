# Skills：超安全的私有提示词与技能存储，现已登陆 Swarms Cloud

你的提示词是知识产权。如果你真正花过时间构建智能体，你的双手早已体会过这句话的分量：那条终于让客服智能体不再凭空捏造退款政策的系统提示词，那份能抓住团队真实会犯的 bug 的审查清单，那些经过精心调校、把通用模型变成一个说话像你公司的专家的指令。这些文档需要数周的迭代才能打磨到位，而在今天之前，Swarms Cloud 没有给你一个安全的地方来保存它们。

现在不同了。**Skills** 已上线：[cloud.swarms.world/skills](https://cloud.swarms.world/skills)，一个为你的提示词和技能打造的私有加密库，内置于 Swarms Cloud，所有套餐的所有用户均可使用。Free、Pro 和 Premium 账户全部可用，没有功能限制，也没有付费引导。你的提示词库是基础设施，而如此根本的基础设施不应该被放在付费墙后面。

## Skills 是什么

Skills 是一个个人库页面，具备一个为日常使用而生的工具应有的一切：

- **你保存的所有内容的画廊视图**：每个条目一目了然地展示名称、描述、标签和最近更新时间。
- **覆盖一切的搜索**：名称、描述、标签，以及提示词本身的全文，所以即使你忘了给"关于退款政策的那条"起了什么名字，也能找到它。
- **每个条目都有专属页面。** 每条提示词和技能都拥有自己的 URL，包含完整内容、一键复制、内联编辑和标签管理。把你每天使用的那些加入书签。
- **上传按钮与完整的拖放支持。** 通过一个简单的表单手动添加条目，或者把文件拖到页面任意位置，一次多少个都可以。
- **用标签来整理**：随着库的增长，"production"、"experimental"、"reviews" 和 "marketing" 可以井然有序地分开。

这个名字是有意为之的。除了一次性的系统提示词，这个页面是为**技能（skills）**而构建的：命名的、可复用的指令包，描述智能体可以承担的一项能力。技能比提示词片段更大，比智能体更小；当你希望任何一个智能体懂得按你的方式做代码审查、按你的方式分流工单、或者用你的品牌语气写作时，你交给它的就是这份文档。

## 把你的 Anthropic 技能一起带过来

拖放导入器原生支持 **Anthropic 技能格式**。如果你一直在编写 SKILL.md 文件（这种格式由承载名称和描述的 YAML frontmatter 开头，后接一段 markdown 的指令正文），你可以把这些文件原样拖到页面上，它们会被干净地导入：frontmatter 变成条目的名称、描述和标签，正文变成存储的技能。不需要转换，不需要重新排版，不需要复制粘贴的手术活。

导入器也接受纯 markdown 和文本文件（以文件名命名），以及 JSON 导出（技能对象数组或简单的字符串数组均可）。文件中无法解析的条目会被跳过，并附带清晰的逐条警告，而不是被悄悄丢弃，所以一次上百个文件的导入会准确告诉你哪些成功入库、哪些需要处理。这一点很重要，因为大多数认真的构建者手里都已经有一批散落在 gist、笔记应用和仓库文件夹里的提示词。迁移本应只是一次拖放，现在它就是。

## 超安全：由构造保证，而非口头承诺

这就是 Skills 与把提示词粘贴进笔记应用的本质区别，而且值得精确地讲清楚，因为"我们非常重视安全"是每个产品都会说、却少有人能解释的一句话。

Skills 中的每一条提示词正文都以 **AES-256-GCM 静态加密**存储，这是银行和政府工作负载所信赖的认证加密标准。但真正有意思的设计决策不在于密码算法，而在于密钥。Skills 不会用一把密钥覆盖整个平台。相反，加密你提示词的密钥是**从你的账户身份以密码学方式派生的**。你的密钥和另一个用户的密钥完全不同，而你们双方都不需要自己管理任何密钥。

这带来了一个简单的数据库权限检查无法比拟的结果：**错误的账户在数学上就无法解密你的提示词**。认证加密会在解密的同时验证完整性，因此为你的账户加密的内容在其他任何人的密钥下都会直接验证失败。即使在最坏的假设中，某个软件缺陷取出了错误的数据行，另一个用户的会话得到的也只是一把无法读取的锁，而永远不会是你的文字。所有权由密码学强制执行，而不仅仅是一个查询过滤器；数据库本身只存储密文：即使备份泄露或数据库凭证被攻破，得到的也只是加密的数据块，而不是你的提示词库。

你可以在界面上直接看到这种安全姿态。每个技能的页面都带有"Private & encrypted"（私有且加密）标记，提示词面板本身也标注了加密状态，因为一个你看不见的安全属性，就是一个你无法信任的安全属性。

关于范围，有一点坦诚的说明，因为精确比夸张更能建立信任：名称、描述和标签以普通文本存储，以保证搜索和画廊视图的即时响应。真正敏感的部分，也就是提示词内容本身，才是被加密的对象。把你的机密写在提示词正文里，而不是标题里，系统就会保护真正重要的东西。

## 为什么值得拥有一个提示词库

如果你还处在构建智能体的早期阶段，提示词库听起来可能像是为了整理而整理。它不是，而且随着规模扩大，这些理由会不断叠加。

**提示词是智能体工程中杠杆率最高的资产。** 模型会变，架构会变，但一条出色的提示词沉淀了你对领域、边界情况和标准的来之不易的认知。因为关掉了浏览器标签页或删掉了一条笔记而失去它，失去的是真实的工作成果。一个库让这些成果变得持久。

**复用永远胜过重写。** Skills 带来的工作流很简单：把指令写一次，随着学习不断打磨，然后复制到任何需要它的智能体里，无论你是在 Workbench 配置单个智能体、在 Compare 页面排布六个变体、在 Batch 中运行五百个任务，还是在 Playground 组建多智能体集群。在任何技能上点击一下即可复制完整提示词，随时粘贴到你正在构建的地方。

**迭代需要一个家。** 一条还不错的提示词与一条出色的提示词之间，通常隔着十五次修订。当每次修订散落在不同的聊天记录里，你看不出改了什么、为什么改。当提示词住在一个稳定的 URL 上、编辑历史握在你手里，打磨就从偶然变成了刻意。

**一致性是一种竞争优势。** 当你部署的每个智能体都取用同一套精心维护的技能时，你的智能体表现得像一支受过共同训练的团队，而不是一群即兴发挥的散兵。客服、研究和审查智能体全部继承同一套内部规范的公司，交付的产品会比每个智能体都重新发明指令的公司更加连贯。

**而重视隐私不是多虑。** 提示词工程眼下是一条真实的护城河。各个团队互相逆向对方的系统提示词是有原因的。一个默认私有、以加密为设计前提的库，意味着你可以集中你最好的工作成果，而不必集中风险。

## 两分钟即可上手

1. 登录 Swarms Cloud，打开 [cloud.swarms.world/skills](https://cloud.swarms.world/skills)，也可以从导航栏的 Skills 标签进入。
2. 点击 **Add skill** 手动创建你的第一个条目，或者把现有的 SKILL.md、markdown 或 JSON 文件拖到页面任意位置。
3. 打上标签，随手搜索，打开任意技能的页面，把它复制进你的下一个智能体。

学习曲线到此为止。该页面今天起对所有账户、所有套餐免费开放。

## 接下来会走向哪里

Skills 是一段更长远规划的地基。今天的私有库，是明天更深度集成的天然跳板：把技能直接插入智能体配置编辑器而无需复制这一步；以及对于主动选择的用户，把私有库中选定的技能发布到 Swarms Marketplace，让你最好的指令变成产品。私有优先的设计是刻意的：一切都从只属于你开始，任何更公开的动作，都只会因为你的选择而发生。

现在就开始构建你的库：[cloud.swarms.world/skills](https://cloud.swarms.world/skills)。你最好的提示词，值得一个比草稿文件更好的归宿。
