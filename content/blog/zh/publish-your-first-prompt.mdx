# 十分钟发布你的第一个提示词

提示词是你能在 [Swarms Marketplace](https://swarms.world) 上发布的最简单的东西。不需要附带代码，不需要声明依赖，也不需要说明环境变量。你粘贴文本，描述它，决定免费还是付费，然后点击发布。发布本身不收费，如果你选择收费，每笔销售你拿走 90%。

大多数浏览市场的人，手里都有一条对自己格外好用的系统提示词。这篇文章就是为你决定发布它的那一刻写的：一份每一步都带有分钟预算的计时实操指南，最后附上关于先发什么、如何定价的几点说明。

## 什么是提示词商品页

提示词商品页是 swarms.world 上的一个产品页面：名称、描述、图片、分类和标签，再加上放在 **Main Prompt** 标签页里的提示词正文。市场会自动加上一个显示 0 到 100 分 Security Score 的 **Security** 标签页，以及一个 **Chat** 按钮，它把提示词作为智能体的系统提示词直接运行，访客可以在购买前先试用。

如果提示词是免费的，任何人都可以阅读全文，它还会以纯 markdown 的形式提供在 `https://swarms.world/prompt/<id>.md`。如果是付费的，访客能看到商品页、价格和一个 Premium 标记，一次性付款后即可永久查看全文。无论哪种情况，买家都可以在 Chat、Preview 或 Markdown 模式下查看提示词，一键导出到 ChatGPT 或 Claude，或者把它的 id 作为 `marketplace_prompt_id` 传入，直接加载到 Swarms 智能体中。

## 计时开始之前

如果你想接受银行卡付款，在打开表单之前先做一件事。进入账户设置中的 [Seller 标签页](https://swarms.world/platform/account?tab=seller)，选择你的国家，点击 **Set up seller account**。这会把你带到 Stripe 托管的入驻流程，填写收款信息、企业或个人信息，并完成身份验证。整个过程只需几分钟，验证通常即时完成，中途离开也会保存进度。只收加密货币的卖家可以跳过 Stripe，免费提示词则完全不需要任何设置。

## 十分钟实操

### 1. 第 0 到 1 分钟：打开发布页面并选择 Prompt

在 [swarms.world](https://swarms.world) 登录，进入 [swarms.world/launch](https://swarms.world/launch)，选择 **Prompt**。表单会标明哪些字段是必填、哪些是可选。提示词没有实现部分：内容就是提示词本身，再加上常规的名称、描述、图片、分类和标签。

### 2. 第 1 到 3 分钟：添加提示词正文

把提示词粘贴到内容字段，或者把 `.md`、`.mdx` 或 `.txt` 文件拖到表单上，Anthropic 格式的 `SKILL.md` 也可以。导入器会填入提示词正文，并从文件的 frontmatter 中读取名称、描述和标签，而且只会填充你尚未输入过的字段。

这里有两个习惯可以让你在第 4 步少走弯路。让每一条指令都可见：不要用 HTML 注释，不要用编码块。如果提示词确实需要智能体使用 shell 或网络，就在提示词正文里说明原因。

### 3. 第 3 到 5 分钟：标题、描述、分类、标签、图片

注册表搜索会同时匹配商品的名称、描述和标签，所以这几个字段决定了是否有人能找到你。

- **标题。** 用买家会输入的词说明提示词做什么。"临床试验方案审查员"能找到买家，"终极提示词 v3"则不能。
- **描述。** 说明提示词产出什么、面向谁、怎么用。附上一段演示输出：针对一个真实输入，提示词返回结果的简短示例。表单没有专门的字段放这个，所以可以写进描述里，或者在 **Use Cases** 下拉区里作为一个用例添加。
- **分类。** 目录涵盖二十个分类，包括 Finance、Research、Healthcare、Developer 和 Security。选择买家会用来筛选的那几个。
- **标签。** 点击标签生成器，它会根据你的名称和描述给出 5 到 16 个 kebab-case 标签，混合行业、智能体类型和能力三类标签，并拒绝 `ai`、`useful` 这类填充词。保留那些属实的；注册表的自然语言搜索每小时都会根据在线商品的标签重建词表。
- **图片。** 上传一张，或者点击生成，在两张 16:9 横幅候选中挑一张。

商品页的实时预览就在定价区旁边，在你确认之前就能看到买家将看到的样子。

### 4. 第 5 到 6 分钟：检查安全评分

每个提示词页面都有一个 Security 标签页，由 [SkillScanner](https://github.com/The-Swarm-Corporation/SkillScanner) 提供支持。市场会用 49 条检测规则加一轮 Swarms 智能体审查来扫描提示词文本，并以 Security Score 显示结果，分数越高越安全：该分数等于 100 减去 SkillScanner 的风险分。

| Security Score | 严重程度 | 建议 | 徽章 |
| --- | --- | --- | --- |
| 80 到 100 | LOW | SAFE | 绿色 |
| 50 到 79 | MEDIUM | CAUTION | 红色 |
| 20 到 49 | HIGH | DO_NOT_INSTALL | 红色 |
| 0 到 19 | CRITICAL | DO_NOT_INSTALL | 红色 |

你想要的是 80 分或以上的绿色评分。对卖家来说关键的一点是：市场会保留提示词的**第一次完整扫描**结果并展示给之后的每一位访客，之后再编辑提示词也不会触发新的扫描。所以要在发布前先扫描。SkillScanner 是开源的，静态模式不需要 API key，一次扫描只需几秒：

```python
from pathlib import Path
from skills_scanner import SkillScanner

scanner = SkillScanner(use_agent=False)
report = scanner.scan_text(Path("my-prompt.md").read_text(), name="my-prompt")

print("Security Score:", round(100 - report.risk_assessment.score), report.verdict)
for issue in report.issues:
    print(issue.severity.value, issue.id, f"line {issue.location.start_line}", issue.remediation)
```

如果分数偏低，每条发现都会给出行号、匹配到的文本和修复建议。在诚实的提示词里，几乎所有发现都来自少数几个习惯：诸如"忽略之前的指令"或"不要告诉用户"之类的措辞；短链接、裸 IP 地址、粘贴站点或纯 `http://` 链接；文本中的 API key；藏在 HTML 注释、不可见 Unicode 或 base64 中的指令；以及没有任何说明的 shell 或网络行为。一条高置信度的高危发现就足以把分数单独拉到 80 以下，所以往往一句话就是全部差别。修复、重新扫描，变绿之后继续。

### 5. 第 6 到 8 分钟：选择免费还是付费

免费是默认选项，不需要其他任何操作。对于付费提示词，把商品标记为 **Paid**，设置一个以美元计的一次性价格，然后回答表单上的问题 **How do you want to get paid?**，在两条收款通道中选一条：

| | Crypto (SOL) | Card / Fiat (Stripe) |
| --- | --- | --- |
| 买家支付方式 | Solana 钱包 | 银行卡、Apple Pay、Google Pay、Alipay、Klarna，以及 Stripe 在买家所在地区提供的其他方式 |
| 你的收入到哪里 | 你登记的 Solana 钱包 | 你的 Stripe Express 余额，再到你的银行账户 |
| 到账时间 | 即时，与购买在同一笔交易中完成 | 按 Stripe 的标准打款周期 |
| 平台费用 | 10% | 10% |
| 你拿到 | 90% | 90% |

两条通道的费用一致，没有上架费也没有最低限额：一个 20 美元的提示词，你拿到 18.00 美元。收款通道是按商品选择的，所以你可以在同一个账户下，一个提示词走银行卡，另一个收 SOL。如果你选了 Card / Fiat 而 Stripe 账户尚未激活，表单会阻止发布并把你指回 Seller 标签页。如果你选了加密货币但没有设置收款钱包，[Seller Portal](https://swarms.world/platform/seller) 会给该商品打上 **No payout wallet** 的警告，直到你添加为止。

你还会看到一个代币化选项。这是一个单独的决定，[智能体代币化完整指南](/blog/complete-guide-tokenizing-your-agent)有详细介绍，而一个普通的免费或付费提示词才是最合适的首次发布。

### 6. 第 8 到 9 分钟：发布

点击发布。在商品上线之前，一个发布评审器会阅读名称、描述和完整提示词，给出 0 到 5 的评分和一段简短的书面理由。免费商品需要达到 2.5 分，付费商品需要达到 3.5 分，评审理由会作为一条评价写入市场。如果描述诚实、提示词言行一致，这一步只是走个形式。

你的提示词现在有了自己的页面，会出现在[注册表](https://swarms.world/platform/registry)中，也会显示在你的公开主页 `swarms.world/users/<your-username>` 上。

### 7. 第 9 到 10 分钟：打开商品页并运行第一次扫描

打开新页面，点击 **Security** 标签页。如果还没有报告，这会触发第一次扫描（需要登录，最多可能需要一分钟）。因为你在第 4 步已经扫描过文本，结果应该一致，绿色徽章会在下次加载页面时出现在横幅中。点击 **Chat**，像买家一样把自己的提示词运行一遍。然后打开 [Seller Portal](https://swarms.world/platform/seller)：如果显示 **Finish setting up** 横幅，它会准确列出哪些问题会导致买家付款无法到达你，并附上每一项的修复链接。横幅消失，你就完成了。

## 发布之后会发生什么

**Seller Portal 成为你的主页。** 它显示最近 30 天扣除费用后的收入和销量、你的平均评分、按收入排序的商品表、说明银行卡、加密货币和代币收入分别流向哪里的 Payouts 区块，以及把你所有商品的最新评价和评论汇总在一起的信息流。[销售页面](https://swarms.world/platform/seller/sales)列出每一笔交易的总额、费用和净额，并可导出为 CSV。在买家的问题变成一笔流失的销售之前，从评价信息流里回答它们。

**智能体也能找到它。** swarms.world 同时也是一个 Model Context Protocol 服务器，地址是 `https://swarms.world/mcp`。任何接入的 MCP 客户端都可以通过 `get_get-prompts` 工具按名称、标签、分类或价格搜索提示词。免费提示词会返回完整正文；付费提示词则返回元数据和一个 `access_info` 对象，直到持有该 key 的账户购买为止。你在第 3 步写下的标签，就是这些智能体用来匹配的依据。

**你的主页在为你工作。** 创作者主页是服务端渲染的，所以你的商品在市场之外也能被找到，你还可以在账户设置里添加最多 500 字符的简介。如果你订阅了 Pro（每月 19.99 美元）或 Premium，用户名旁边会出现蓝色的 **Verified** 徽章，你的产品也会被推荐给其他用户。这个徽章表示账户有一个生效中的付费方案；它与 Stripe 为收款而进行的身份验证是两回事。详情见 [swarms.world/verified](https://swarms.world/verified)。

## 先发布什么

提示词适合角色设定、任务指令和结构化输出模板。最好的第一个商品，是你自己复用最多的那条提示词，因为你清楚它会产出什么，也能把一段真实输出贴出来当演示。窄胜于宽：一条能稳定完成某个具体任务的提示词，更容易描述、更容易被找到，也更容易获得好评。

收费之前没有任何门槛；任何账户第一天就可以发布付费商品。即便如此，先发一个免费提示词也是合理的做法：所有人和 MCP 上的所有智能体都能读到它，而它积累的评分会留在你的主页上，等你发布付费商品时派上用场。

## 定价判断

价格是一次性的，买家获得永久访问权。市场上聚焦型提示词的定价通常在 1 到 50 美元左右。有用的问题是：买家自己做出同等效果需要多少时间或专业知识，然后把价格定在那之下。决定之前，先在[注册表](https://swarms.world/platform/registry)里浏览类似的提示词。

几个具体的点：

- 无论价格和通道，费用都是 10%，所以一个 10 美元的提示词给你 9.00 美元。
- 银行卡付款能触达 100 多个国家不持有加密货币的买家，所以面向企业的提示词应选择银行卡通道。
- 付费提示词的完整 Security 报告只有你和你的买家能看到，但徽章是公开的，这是发布前把分数做到绿色的又一个理由。
- Pro 的费用大约相当于每月一笔销售，如果你打算销售，徽章和推荐通常能把这笔钱赚回来。

你之后可以在产品页面上编辑商品，Seller Portal 的收入图表会在几天内显示改动是否带来了变化。
