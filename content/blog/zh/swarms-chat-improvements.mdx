# 全新的 Swarms Chat 体验正式上线

[Swarms Marketplace](https://swarms.world) 上的每一个提示词都有一个 Chat 按钮。点击它，你就在与一个以该提示词作为系统提示词、由 Swarms API 驱动的智能体对话。这是在购买、复刻或基于某个提示词继续构建之前，试用它的最快方式。

我们从头重新设计了这个体验。聊天现在是全屏的，背后的智能体可以完全自定义，顶栏整合为一组风格统一的控件，模型选择器几乎列出了 Swarms API 能运行的所有模型。本文将逐一介绍这些变化以及如何使用它们。

## 全屏聊天

以前，聊天窗口是在产品页面内部打开的，与侧边栏和导航栏共享屏幕。问个简单的问题没有问题，但一旦对话变长，空间就显得局促。

现在，聊天会作为一个独立的全屏页面打开。在任意提示词上点击 **Chat**，侧边栏和导航栏就会消失。对话占据整个视口，输入框位于底部你所期待的位置，长回复也可以直接阅读，不必再在页面里的一个小框内滚动。

顶栏的 **Back to product** 按钮会在你完成后带你回到商品页，所以浏览和发现的方式没有任何改变。你依旧按原来的方式逛市场，只是聊天本身有了更多空间。如果你更喜欢嵌入式视图，顶栏的 **Fullscreen** 开关可以在两种模式之间切换。

## 自定义你的智能体

这是最大的变化。聊天顶栏新增了一个 **Settings** 面板，它暴露了你正在对话的提示词的完整 Swarms `AgentSpec`。所有你在直接调用 `/v1/agent/completions` 时能设置的参数，现在都可以在聊天里设置。

提示词本身拥有三个字段：名称、描述和系统提示词。这三项保持固定，因为它们定义了这个提示词之所以是这个提示词。其余的一切都由你来调整：

- **最大循环次数。** 设定固定的推理循环次数，或者切换到 `auto`，让智能体自行判断任务何时完成。在 auto 模式下，智能体会获得自主工具集：规划、思考、文件操作以及子智能体。
- **采样参数。** Temperature、top-p、最大 token 数和动态 temperature。
- **推理。** 推理强度从 `minimal` 到 `max`，思考 token 预算，以及针对支持的模型开启或关闭扩展推理的开关。
- **MCP 服务器。** 通过 URL 或完整配置将智能体指向一个或多个 MCP 服务器，它就可以在对话过程中调用这些服务器暴露的工具。
- **工具。** 直接附加工具定义，选择智能体的哪些工具处于激活状态，并决定是否在回复中对工具调用进行摘要。
- **备用模型。** 指定一个或多个备用模型，在主模型出错或不可用时自动切换。
- **流式输出。** 逐 token 实时输出，或等待完整回复。如果某个模型的流式输出失败，聊天会自动以普通补全的方式重试。

设置会按提示词保存在你浏览器的本地存储中。不会写入你的账户，不会与任何人共享，下次打开该提示词的聊天时，你的配置会原样保留。点击 Reset 即可一键恢复该提示词的默认设置。

对提示词作者而言，这意味着聊天现在是一个忠实的测试台。你在设置面板中调好的配置，与你会发送给 API 的规范完全一致，所以在聊天里有效的配置，在生产环境中同样有效。

## 更简洁的顶栏

聊天顶栏过去堆放着来自不同功能的按钮，每个按钮的样式各不相同。现在它是风格统一的一行：

- **Model** 模型选择器。
- **Web search** 开关，需要时让智能体获取实时搜索结果。
- **Settings** 智能体规范设置。当你的设置与默认值不同时，图标会亮起。
- **Reset** 重置对话。
- **Fullscreen** 全屏开关，适用于你从产品页面内部打开聊天的场景。
- **Back to product** 返回产品页。

每个按钮的尺寸、颜色和悬停状态都保持一致，并且每个按钮在悬停时都会显示简短提示，你再也不用猜测某个图标的作用。

## 从近 2,000 个模型中选择

旧的模型选择器是一个简短的固定列表。新的选择器会向 Swarms API 查询当前可用的模型并全部展示。截至本文发布，共有 1,947 个模型，来自 OpenAI、Anthropic、Google、xAI、Meta、DeepSeek、Moonshot、智谱，以及通过 OpenRouter 路由的数十家提供商。

这么长的列表需要结构，所以选择器做了以下设计：

- **精选模型置顶。** Claude 5 系列、GPT-5.4 及更新版本、GLM 5 和 Kimi K3 固定在列表顶部，最新版本排在最前。
- **搜索。** 开始输入，列表就会缩小到匹配的模型 ID。如果你知道自己想要哪个模型，敲几个键就能选中。
- **提供商标签。** 每个条目都会显示由哪家提供商提供服务，所以 `openrouter/moonshotai/kimi-k3` 与第一方模型一眼就能区分。
- **紧凑且自适应。** 菜单会根据内容自动调整尺寸，使用更小的字号以完整显示较长的模型 ID，并在上方空间比下方更充裕时向上展开。
- **清晰的选中状态。** 当前使用的模型以绿色高亮显示。

任何 API 接受的模型，聊天都接受。你可以在对话中途切换模型，用相同的设置比较两个模型对同一个提示词的处理方式。

## 立即体验

打开 [swarms.world](https://swarms.world) 上的任意提示词并点击 **Chat**。全屏页面、设置面板和新的模型选择器今天已对市场上的每一个提示词生效。无需更改账户，无需新的密钥，提示词作者也无需做任何操作。

如果你还没有构建过提示词，聊天也是一个不错的起点：挑一个接近你需求的提示词，调整它背后的智能体直到它按你的想法工作，然后复刻它，让它成为你自己的作品。

## 分发并变现你的提示词

这个全新聊天中的每一个提示词，都是某个人发布的产品。你的提示词也可以成为其中之一。

把你的提示词和技能变成 Swarms Marketplace 上的产品。你可以免费发布，也可以设定固定价格，每当有人购买访问权限时获得收入。将提示词代币化后，你还能额外从其代币的每一笔交易中获得分成。市场负责发现、支付、评价，现在还提供一个让买家在下单前用任意模型试用你作品的聊天。
