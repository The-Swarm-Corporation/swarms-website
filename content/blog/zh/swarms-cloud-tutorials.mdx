# 学习在 Swarms Cloud 上构建多智能体系统：两部全新视频教程

两部全新视频教程现已上线，讲解 Swarms Cloud 上最强大的两个功能：Auto Agent Builder 与 Compare。两部教程均由我们的联合创始人兼 CEO Kye Gomez 亲自讲解，从头到尾演示平台上的真实工作流。

教程内容包括：

- 使用 Auto Agent Builder，从一段自然语言描述生成完整的 AI 智能体团队
- 使用 Compare，让多个智能体同时执行同一任务，并排评估它们的输出
- 充分利用 Swarms Cloud 的最新功能

更多教程正在制作中，一套完整的 Swarms Cloud 课程也在筹备中，帮助你从基础入门一路进阶到构建高级智能体工作流。

## 教程一：用自然语言生成 AI 智能体团队（Auto Agent Builder）

第一部教程介绍 Swarms Cloud 上的 Auto Agent Builder。你用日常语言描述一个任务，构建器就会自动设计出一支完整的智能体团队：专业化的角色分工、系统提示词、模型选择与生成参数，全部在几秒内配置完成。

视频完整走过这个功能的使用流程，从撰写最初的任务描述，到审阅和编辑生成的智能体。如果你一直在手工搭建智能体团队，逐个编写系统提示词、逐个挑选模型，这部教程会让你看到构建器如今能替你完成多少工作。

[在 YouTube 上观看](https://www.youtube.com/@kyegomez3242)

想阅读该功能的完整图文介绍，请看 [Auto Agent Builder 发布公告](/zh/blog/introducing-auto-agent-builder)。

## 教程二：并排对比 AI 智能体（Compare）

第二部教程展示 Swarms Cloud 上的 Compare 功能。Compare 可以让你把同一个任务同时交给多个 AI 智能体执行，并把它们的回答并排呈现。

这解决了每个智能体开发者都会遇到的问题：模型、提示词或参数不同的两个智能体会产出不同的结果，而在它们之间做选择，唯一可靠的方式是让它们跑同一个输入。Compare 把这种评估变成了一步操作：任务只需运行一次，把输出放在一起阅读，然后保留表现最好的配置。

[在 YouTube 上观看](https://www.youtube.com/@kyegomez3242)
