# Swarms Launchpad 更新：全面迁移至 Meteora DBC，支持 $SWARMS 交易对，发行速度提升 80%

[Swarms 市场](https://swarms.world)上的每一个代币化智能体和提示词，现在都直接在 [Meteora 动态绑定曲线](https://www.meteora.ag)（Dynamic Bonding Curve，简称 DBC）上发行。在此之前，发行流程需要经过 Jupiter Studio 这一中间层。现在，我们使用 Meteora 的 DBC SDK 自行构建发行交易，通过我们自己的 RPC 发送，并直接从链上读取和领取费用。

对创作者来说，这带来了三项核心变化：

1. **你可以用 $SWARMS 作为代币的交易对。** SOL 和 USDC 依然可用，$SWARMS 成为第三种流动性交易对。
2. **你可以以 $SWARMS 赚取创作者费用。** 费用以资金池所配对的代币支付，因此 $SWARMS 资金池会以 $SWARMS 向你支付费用。
3. **发行速度提升约 80%。** 流程中不再有第三方平台，你的代币从点击“发布”到正式上线所需的时间大幅缩短。

除此之外还有更多底层改进，详见下文。

## 以 $SWARMS 发行代币

![以 $SWARMS 为交易对发行智能体，同时支持 SOL 和 USDC](/launch_agents_with_swarms.png)

在将智能体或提示词代币化时，你需要选择代币的交易对资产。现在，除了 SOL 和 USDC，你还可以选择 $SWARMS（`74SBV4zDXxTRgv1pEMoECskKBkZHc2yGPnc7GYVepump`）。

以 $SWARMS 为交易对的代币，在绑定曲线上使用 $SWARMS 进行买卖。买家无需事先持有 $SWARMS：在 Jupiter 上用 SOL 购买的买家，会被自动按 SOL → $SWARMS → 你的代币的路径完成兑换。

毕业门槛以美元计价，因此每种交易对的表现都一致。每条曲线的起始市值约为 3,246 美元，在约 46,468 美元时毕业。对于 SOL 和 $SWARMS 资金池，我们会在你发行时按实时价格换算这些数值。

以 $SWARMS 发行的方式：

- 在[发行页面](https://swarms.world/launch)打开代币化（Tokenization），并选择 $SWARMS 作为流动性交易对。
- 或者打开[已预选 $SWARMS 的快速发行（Quick Launch）](https://swarms.world/quick-launch?pair=swarms)。

## 以 $SWARMS 赚取费用

创作者费用以资金池的报价代币支付。以 $SWARMS 为交易对发行，你的代币每一笔交易都会以 $SWARMS 支付你的分成。以 SOL 或 USDC 为交易对发行，则和以前一样以 SOL 或 USDC 支付。

费率档位保持不变：

| | 标准 | Frenzy Mode |
| --- | --- | --- |
| 每笔交易手续费 | 1% | 2% |
| 创作者分成 | 扣除 Meteora 协议费后的一半 | 扣除 Meteora 协议费后的一半 |

变化在于你的分成存放在哪里。Jupiter Studio 通过自己的费用分成金库向创作者付款，而链上记录的创作者分成为 0%。在 Meteora DBC 上，你的 50% 分成会在资金池创建时直接写入链上配置，任何中间方都无法更改。

费用会以资金池本身的币种显示在账户的 Fees 标签页中。你可以像以前一样，在钱包中签署一笔交易来领取费用。

## 毕业后持续赚取收益

当代币达到毕业市值时，其流动性会从绑定曲线迁移到 Meteora DAMM v2 资金池。本次更新后，这部分流动性按创作者 50%、平台 50% 分配，并且两部分都会被**永久锁定**。

这为创作者带来了第二条长期收入来源。只要代币还在交易，你锁定的流动性头寸就会持续从毕业后的资金池中赚取交易手续费。流动性永远无法被撤出，这也让持有者确信它会一直存在。

## 发行速度提升约 80%

现在，一次发行就是一笔交易：由我们构建，你在钱包中签名一次，再由我们通过自己的 Helius RPC 提交。不再需要往返第三方平台，也无需等待外部上传。实际使用中，发行速度比通过 Jupiter Studio 时快了约 80%。

## 更多改进

- **`swrm` 代币地址。** 新代币的铸币地址以 `swrm` 结尾，在 Solscan、Jupiter 或任何交易终端上都能一眼认出这是 Swarms 发行的代币。这些地址由我们在后台预先生成，因此不会增加你的发行时间。
- **由我们托管的元数据。** 代币的图片和元数据存储在 Swarms 自己的基础设施上，外部存储服务不会再阻断或破坏发行。
- **更安全的代币默认设置。** 每个代币的总供应量固定为 10 亿，没有铸币权限、没有冻结权限，元数据不可更改。发行之后，任何人都无法增发、冻结持有者，或修改你的代币信息。
- **明确的名称和代码长度限制。** 名称最多 32 字节，代码（Ticker）最多 10 字节。我们会在你发布前检查两者，超长的名称会得到清晰的提示，而不是在列表上线后才在链上失败。
- **快速发行先铸币。** 快速发行现在会先创建代币，再发布智能体。如果铸币失败或你在钱包中拒绝签名，就不会再留下一个没有代币的列表。

## 今天之前发行的代币怎么办？

它们不受任何影响。通过 Jupiter Studio 发行的代币照常交易，其创作者费用依然可以在同一个 Fees 标签页中查看和领取。只有新发行的代币使用 Meteora DBC。

## 如何立即发行

1. 前往 [swarms.world/launch](https://swarms.world/launch) 或[快速发行](https://swarms.world/quick-launch)。
2. 填写你的智能体或提示词信息，然后打开代币化。
3. 设置最多 10 个字符的代码，并选择流动性交易对：SOL、USDC 或 $SWARMS。
4. 你可以选择开启 [Frenzy Mode](/zh/blog/frenzy-mode-tokenized-agents) 以使用 2% 费率档位，或开启 [Vault Mode](/zh/blog/vault-mode-tokenized-agents) 将使用权限仅限持有者。
5. 连接你的 Solana 钱包，点击发布，并签署一次发行交易。

你的代币将以 `swrm` 地址上线，创作者分成写入链上。从第一笔交易起就开始赚取费用，毕业后依然持续获得收益。如需全面了解代币化智能体的运作方式，请阅读[《代币化智能体：它是什么、如何发布，以及创作者如何获得持续收益》](/zh/blog/tokenized-agents-launch-revenue)。

## 常见问题

**购买以 $SWARMS 为交易对的代币，买家需要持有 $SWARMS 吗？**
不需要。在 Jupiter 上用 SOL 支付的买家会被自动通过 $SWARMS 完成兑换。

**$SWARMS 资金池的创作者费用是以 $SWARMS 支付的吗？**
是的。费用以资金池的报价代币支付，因此 $SWARMS 资金池以 $SWARMS 支付创作者费用。

**费率有变化吗？**
没有。标准模式仍为 1% 交易手续费，Frenzy Mode 仍为 2%。创作者的一半分成现在直接写入资金池的链上配置。

**代币毕业后会发生什么？**
其流动性会迁移到 Meteora DAMM v2 资金池，在你和平台之间按 50/50 分配并永久锁定。你的那一半会持续赚取交易手续费。

**本次更新前发行的代币需要我做什么吗？**
不需要。旧代币照常运作，你可以像以前一样在 Fees 标签页领取费用。
