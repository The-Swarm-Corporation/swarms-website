# 推出 Explorer：实时追踪 Swarms 市场的增长数据

今天，我们正式发布 [Explorer](https://swarms.world/explorer)。这是 [Swarms 市场](https://swarms.world)上的一个全新页面，实时展示市场的增长情况。它把所有核心数字集中在一处：市场上有多少产品、有多少人在出售、今天新发布了多少，以及在市场上发行的代币累计赚取了多少费用、产生了多少交易量。

页面打开后会自动更新。把它留在浏览器标签页里，你就能看着这些数字随着开发者发布新产品而不断上涨。

![Swarms 市场 Explorer：总产品数、卖家收入、累计交易量，以及智能体、提示词和工具](/explorer_overview.png)

## Explorer 展示了什么

Explorer 由一组卡片组成，每张卡片回答一个关于市场的问题。

| 卡片 | 统计内容 |
| --- | --- |
| 总产品数（Total products） | 市场上所有的智能体、提示词、工具和组合包 |
| 卖家创造的收入（Revenue Generated by Vendors） | 市场上发行的代币累计赚取的交易费用，包含创作者和平台两部分 |
| 累计交易量（All-time volume） | 上述代币的累计交易量 |
| 智能体、提示词、工具总数 | 每种产品类型的单独统计 |
| 产品发布（Product launches） | 过去 24 小时内新发布的各类产品 |
| 卖家总数（Total sellers） | 至少发布过一个产品的账户 |
| 付费产品（Paid products） | 设有价格的产品，可用银行卡、SOL 或 USDC 购买 |
| 代币化产品（Tokenized products） | 拥有独立代币的智能体和提示词 |
| MCP 智能体（MCP agents） | 提供 MCP 服务器的智能体 |

截至撰写本文时，市场共有 6,400 个产品，来自 808 位卖家：其中智能体 5,576 个、提示词 773 个、工具 46 个。付费产品 214 个，代币化产品 996 个，提供 MCP 服务器的智能体 24 个。

每张计数卡片还附带一个小图表。大多数卡片展示过去 30 天每天新增的数量，你可以一眼看出一个数字是在稳步增长，还是在某一周突然跃升。产品发布卡片则按小时展示过去 24 小时的情况。

![智能体、提示词、工具、产品发布、卖家、付费产品、代币化产品和 MCP 智能体，每张卡片都带有 30 天趋势图](/explorer_cards.png)

## 实时更新

大多数数据面板展示的是一张快照，打开的那一刻就已经过时了。Explorer 在标签页可见时每五秒刷新一次，数字变化时每一位都会滚动到新的数值。

- **产品计数**会在新产品发布后 30 秒内更新。
- **收入和交易量**每次刷新都直接从 Solana 链上读取，因此市场上任何代币的一笔交易，几秒内就会反映在页面上。
- **隐藏的标签页会暂停刷新**，只有在有人查看时页面才会工作。

这个页面是公开的。你无需账户即可访问，也可以把链接分享给任何人。

## 开发者可以如何使用它

### 发现市场空白

产品分类数据让供给不足的领域一目了然。智能体的数量是工具的一百多倍，而目前只有 24 个智能体提供 MCP 服务器。如果你开发了实用的工具或 MCP 服务器，现在这些类别里几乎没有竞争。可以从 [MCP 门户](/zh/blog/mcp-portal-swarms-marketplace)开始。

### 发布前先看势头

30 天趋势图和 24 小时产品发布卡片，能告诉你在你准备发布的那一刻，市场有多活跃。卖家曲线上升，说明有更多开发者加入；发布数量激增，说明当天有更多产品在争夺首页位置。

### 决定如何定价

付费产品和代币化产品的数量并排展示，你可以看到其他开发者选择了哪种赚钱方式。付费产品按每次销售获得收入，支持银行卡或加密货币（参见[如何出售智能体和提示词](/zh/blog/how-to-sell-agents-prompts-stripe-crypto)）。代币化产品则从其代币的每一笔交易中获得分成（参见[代币化智能体如何持续创造收入](/zh/blog/tokenized-agents-launch-revenue)）。

### 关注代币经济

“卖家创造的收入”和“累计交易量”这两张卡片表明，市场上的代币交易活跃，这些交易产生的费用是真实的收入。市场上代币的每一笔交易都会支付费用，创作者在发行后无需任何额外操作即可获得分成。这两张卡片就是市场上所有代币这些活动的累计总额。

### 分享数据

无论你是在推介自己的智能体、撰写关于智能体经济的文章，还是只想让别人看看 Swarms 上正在构建什么，Explorer 都是一个带有最新数据的链接。

## 数据从何而来

我们希望页面上的每一个数字都可以追溯，下面是每个数字的具体计算方式。

- **产品、智能体、提示词、工具和产品发布**直接根据市场的产品列表统计，没有抽样，也没有估算。
- **卖家**是至少发布过一个产品的账户，从其首次发布产品的日期开始计入。
- **付费产品**设有价格且没有代币；**代币化产品**拥有代币。这与市场定价筛选器使用的规则相同。
- **MCP 智能体**是带有 MCP 类别标签的智能体。任何填写了 MCP 服务器地址的智能体在发布时都会自动获得这个标签。
- **卖家创造的收入**从每个代币在 Solana 上的资金池读取：包括它在 [Meteora](https://www.meteora.ag) 上的绑定曲线，以及毕业后迁入的资金池。它同时涵盖通过 Jupiter Studio 发行的代币和直接在 Meteora 上发行的代币（[迁移详情见此](/zh/blog/swarms-launchpad-meteora-dbc)）。它包含创作者和平台从交易费用中获得的部分（无论是否已领取），不包含 Meteora 的协议费用。
- **累计交易量**根据上述费用计算。每个资金池都会记录已收取的费用，并按固定费率对每笔交易收费（根据资金池不同为 1% 或 2%），因此用费用除以该资金池的费率即可得出交易量。代币刚上线的最初几分钟内，交易可能需要支付更高的反狙击费用，因此这是一个接近实际的估算值。
- **美元计价：** USDC 按 1 美元计算，$SWARMS 使用实时价格。SOL 按固定的参考价格换算，而不是实时市场价格，因此这两张卡片反映的是交易活动，不会随 SOL 价格的波动而变化。

## 如何访问

1. 前往 [swarms.world/explorer](https://swarms.world/explorer)，或点击市场侧边栏中排行榜下方的图表图标。
2. 点击任意卡片即可查看详情。智能体、提示词和工具卡片会打开按该类型筛选的注册表，付费产品卡片打开付费产品列表，代币化产品卡片打开[智能体代币筛选器](https://swarms.world/screener)，MCP 智能体卡片打开 MCP 服务器页面，卖家总数卡片打开排行榜。

## 常见问题

**查看 Explorer 需要账户吗？**
不需要。页面是公开的，未登录也可以访问。

**数字多久更新一次？**
页面打开时每五秒更新一次。新产品会在发布后 30 秒内计入统计。

**收入是否包含迁移到 Meteora 之前发行的代币？**
包含。收入和交易量涵盖市场上发行的所有代币，无论是通过 Jupiter Studio 发行，还是直接在 Meteora 上发行。

**“30D”标签是什么意思？**
该卡片上的图表展示过去 30 天每天新增的数量。大数字始终是累计总数。

**为什么工具和 MCP 智能体这么少？**
它们目前在市场产品中的占比还很小，这正是现在值得去构建的原因。产品越少，每一个获得的曝光就越多。
