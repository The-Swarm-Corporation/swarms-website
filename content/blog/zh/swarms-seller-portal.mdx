# 推出卖家中心：收入、商品、销售与收款，尽在一处

今天，我们正式发布[卖家中心](https://swarms.world/platform/seller)（Seller Portal），这是为所有在 [Swarms 市场](https://swarms.world)上销售产品的卖家打造的全新主页。卖家最常问的问题，现在都能在一个页面上找到答案：我赚了多少？哪些商品卖得好？谁买了它们？大家怎么评价？有没有什么问题会导致我收不到钱？

在此之前，这些信息分散在账户设置、各个产品页面和 Stripe 后台之中。卖家中心把它们集中到了一起，新的销售页面还提供了每一笔交易的完整记录，支持搜索，并可导出为电子表格。

## 页面包含哪些内容

卖家中心从上到下由以下几个部分组成。

![完整的卖家中心：核心指标、收入图表、商品列表、最近销售、评价和评论，以及收款](/seller_portal_full_page.png)

| 模块 | 显示内容 |
| --- | --- |
| 核心指标 | 最近 30 天的收入和销量，以及你的平均评分 |
| 完成设置 | 任何会导致买家付款无法到达你账户的问题 |
| 收入 | 最近 30 天或 90 天每日银行卡与加密货币收入图表 |
| 你的商品 | 你发布的所有智能体、提示词、工具和套装，以及各自的销量和收入 |
| 最近销售 | 最近 10 笔销售，并可跳转查看完整记录 |
| 最新评价和评论 | 其他人在你的商品下留下的内容 |
| 收款 | 银行卡、加密货币和代币收入分别流向哪里，以及在哪里管理 |

### 核心指标

页面顶部有三张卡片：

- **收入（30 天）**：最近 30 天你实际到手的金额，已扣除平台费用。
- **销量（30 天）**：同一时间段内完成的销售笔数。
- **平均评分**：你所有商品的平均评价分数，以及评价的数量。

收入始终显示为**扣除费用后的净额**。无论买家使用银行卡还是加密货币付款，Swarms 都对每笔完成的销售统一收取 10% 的费用，你保留 90%（[完整费用说明见此](/blog/how-to-sell-agents-prompts-stripe-crypto)）。卡片上的数字就是这 90%，与实际进入你 Stripe 余额或钱包的金额一致。

### 完成设置

只有当某些问题会导致你收不到钱时，这个提示栏才会出现。它会明确列出需要处理的事项，并为每一项提供修复链接：

- **发布你的第一个商品**：如果你还没有发布任何内容。
- **连接 Stripe 以接收银行卡付款**：如果你有以银行卡定价的商品，但还没有可用的 Stripe 账户。
- **添加收款钱包**：如果有加密货币商品尚未设置收款钱包。这些商品也会在商品列表中被标记出来，方便你快速找到。

一切就绪后，提示栏会自动消失。

### 收入图表

收入图表以堆叠柱状图显示你每天的收入，并区分**银行卡**销售和**加密货币**销售。你可以在最近 30 天和 90 天之间切换，看看一次发布、一次调价或一次外部推荐是否带来了变化。

### 你的商品

![核心指标、按银行卡和加密货币区分的 30 天收入图表，以及按收入排序的商品列表](/seller_portal_overview.png)

你发布的所有产品都集中在一张表格中：缩略图、名称、类型、价格、销量、收入、评分和点赞数。商品按收入排序，表现最好的始终排在最前面，每页显示 10 个。

- **搜索**：按名称查找特定商品。
- **仅看付费**：一键筛选出你的付费商品，并显示数量。
- 对于需要设置钱包才能收款的加密货币商品，旁边会显示**无收款钱包**提醒。

点击任意商品即可打开其产品页面，并像以前一样进行编辑。

### 最近销售

最近的 10 笔销售显示在商品列表下方，点击**查看全部销售**按钮即可打开完整的销售页面。

### 最新评价和评论

其他人在你的商品下留下的评价和评论会汇总到同一个列表中。你不再需要逐个打开产品页面，就能知道是否有人提问或打分。

### 收款

收款模块说明了每一类收入的去向，并链接到对应的管理位置：

- **银行卡销售（Stripe）**：显示你的 Stripe 账户是已连接、仍在设置中，还是尚未连接。点击**管理银行卡收款**会打开账户设置中的卖家选项卡。
- **加密货币销售**：买家付款后，款项会立即直接打入每个商品所设置的钱包。如果有商品缺少钱包，这里会显示数量。
- **代币创作者费用**：如果你[将商品代币化](/blog/tokenized-agents-launch-revenue)，你可以从该代币的每一笔交易中获得分成。点击**领取创作者费用**即可前往领取。

## 销售页面：每一笔交易，均可导出

全新的[销售页面](https://swarms.world/platform/seller/sales)完整记录了你卖出的所有内容，按时间从新到旧排列。每一行显示：

| 列 | 含义 |
| --- | --- |
| 日期 | 销售发生的时间 |
| 商品 | 被购买的商品 |
| 买家 | 买家的公开 @用户名 |
| 支付方式 | 银行卡或加密货币 |
| 总额 | 买家支付的金额 |
| 费用 | 10% 的平台费用 |
| 净额 | 你实际收到的金额 |
| 状态 | 付款是否完成 |

加密货币销售还附有 [Solscan](https://solscan.io) 交易链接，你可以随时在链上自行核实每一笔付款。

页面顶部显示你的累计数据：已完成的销售笔数，以及扣除费用后的总收入。一个搜索框即可按商品、@买家、支付方式、状态或交易签名进行筛选，结果每页显示 25 条。

### 导出为 CSV

点击**导出 CSV**，即可将当前显示的记录（包括你已应用的搜索筛选）下载为电子表格。一些细节让这个文件更好用：

- 在 Excel、Google Sheets 和 Numbers 中都能正常打开，包含重音符号或非拉丁字符的名称也能正确显示。
- 每笔金额都拆分为总额、费用和净额，让记账和报税更加简单。
- 商品名称由卖家自行填写，因此任何可能被电子表格当作公式执行的内容都会在导出前做安全处理。

## 如何打开

1. 登录 [swarms.world](https://swarms.world)。
2. 点击侧边栏中 Developers 下方的 **Seller Portal**，或直接访问 [swarms.world/platform/seller](https://swarms.world/platform/seller)。
3. 点击**查看全部销售**打开完整的销售页面，或点击右上角的**发布商品**添加新产品。

即使你还没有任何销售，页面也能正常使用。它会引导你完成需要的设置，并在第一笔销售到来时逐步填充各个模块。

## 隐私与准确性

- **你只能看到自己的数据。** 两个页面上的每一个数字和每一行记录，都只来自你自己的商品和销售。
- **买家仅以公开 @用户名显示。** 卖家永远看不到买家的电子邮件地址或任何其他私人信息。
- **总计只统计已完成的销售。** 销售表格会列出每一笔交易，包括未完成的交易，让你掌握完整情况；而核心指标和收入只计入真正付款成功的交易。
- **大型商品目录也能完整统计。** 拥有数千个商品或销售记录的卖家，看到的也是完整的总计，而不是抽样数据。

## 如何充分利用卖家中心

- **先清除提示栏。** 如果"完成设置"正在显示，说明买家此刻可能无法向你付款。修复只需一分钟。
- **每次调整后关注 90 天图表。** 新定价、新图片或一次代币化发布，都会在几天内反映在柱状图上。
- **在一个地方回复评论。** 评价列表是最快发现买家疑问的方式，避免错失一笔销售。
- **每月导出一次。** 每月一份 CSV，为你自己的记账提供清晰的记录。

刚开始销售？请先阅读我们的[智能体和提示词销售分步指南](/blog/how-to-sell-agents-prompts-stripe-crypto)，然后使用卖家中心追踪商品的表现。

## 常见问题

**谁可以使用卖家中心？**
任何拥有 Swarms 账户的人。登录后从侧边栏打开即可。如果你还没有发布任何内容，它会告诉你如何开始。

**收入是扣费前还是扣费后？**
扣费后。收入是你实际保留的部分，即每笔完成销售的 90%。

**是否包含加密货币销售？**
包含。银行卡和加密货币销售都会计入总计、显示在图表中，并列在销售页面上。

**买家能看到我的销售情况吗？**
不能。卖家中心和销售页面仅对你本人可见。

**我能看到谁买了我的商品吗？**
你可以看到买家的公开 @用户名，从而了解你的客户是谁，但永远看不到他们的电子邮件地址。

**可以在卖家中心编辑商品吗？**
点击商品打开其产品页面，然后像往常一样在那里编辑。

**代币交易费用显示在哪里？**
代币化商品的创作者费用需要单独领取，入口在账户中的创作者费用（Creator Fees）选项卡。收款模块中提供了直达链接。
