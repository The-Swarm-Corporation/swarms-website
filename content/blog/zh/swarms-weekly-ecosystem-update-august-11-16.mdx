# Swarms 生态每周更新 [8 月 11 日 - 8 月 16 日]：代币化智能体 Screener、GMGN 集成，以及全新 Cloud 视频教程

本周的工作集中在 Swarms 平台的市场层：代币化智能体如何被发现、追踪和交易。Screener 正式上线，为 Marketplace 上的每一个代币化智能体提供一个专属的实时视图；GMGN 集成则把这种可发现性延伸到了 Swarms 之外，让 Swarms 智能体直接出现在 Solana 最大的交易平台之一的交易者面前。

两个发布背后的共同主题是分发。一个已发布但难以被找到的智能体，几乎等同于不存在。在此之前，Marketplace 的代币化板块没有一个统一的地方来回答几个基本问题：今天有什么新发布，什么在上升，成交量流向了哪里。Screener 在生态内部回答这些问题，GMGN 则在生态之外、在交易者已经聚集的平台上回答同样的问题。

本周其余的更新补齐了开发者和公司层面：两个新视频教程演示了 Swarms Cloud 上的 Auto Agent Builder 和 Compare 功能，完整课程正在制作中；Vault Mode 竞赛进入最后几天；Swarms API 的错峰定价让夜间代币成本减半；同时，Swarms 面向公司所有职能全面开放招聘。

## Screener：所有代币化智能体，汇聚在一个实时页面

![Swarms Screener](/swarms_screener.png)

Swarms 启动板现在拥有一个专为代币化智能体和提示词打造的 Screener，已上线：[swarms.world/screener](https://swarms.world/screener)。它把整个代币化智能体生态汇聚到一处：按市值排名的热门智能体、接近实时的新代币发布信息流、实时价格、涨跌幅和交易量，以及合约地址、创建者和发布详情，全部在一个视图中呈现。筛选器覆盖 Frenzy Mode、Vault Mode 或两者，可以按具体的发布机制来缩小视图范围。

数据来自链上。Screener 结合 Jupiter 和 Dune 的实时数据源来计算市值、价格、交易量和涨跌幅，因此这些数字反映的是真实的链上状态，而非平台自行上报的数据。对创建者来说，这是第一个能实时展示自己的发布在整个 Marketplace 中所处位置的页面；对其他人来说，这是发现哪些智能体正在获得动能的最快方式。

## Swarms 智能体现已可以在 GMGN 上被发现和交易

![Swarms x GMGN](/swarms_and_gmgn.png)

Swarms 是 Solana 上最大的 AI 启动板，现已与 GMGN 完成集成。你可以在 GMGN 的 Trenches 标签页中直接筛选 Swarms 智能体，也可以把任意智能体的合约地址粘贴到 GMGN 的搜索栏立即找到它，还可以在 Swarms 启动板上通过 GMGN 一键购买代币化智能体。

这次集成的意义在于它把 Swarms 智能体放到了哪里：直接进入那些原本不会先访问 Marketplace 页面的交易者的工作流之中。GMGN 自带分析、发现和交易基础设施，通过让代币化智能体在交易者已经活跃的地方更容易被发现、追踪和交易，这次集成预计将扩大整个 Swarms 生态的流动性。随着启动板规模扩大，更多此类集成正在规划中。

- [了解更多](/zh/blog/swarms-gmgn-integration)

## 两个新视频教程：Auto Agent Builder 与 Compare 功能

![Swarms Cloud 教程](/swarms_cloud_tutorials_banner.png)

联合创始人兼 CEO Kye Gomez 发布了两个新视频教程，实际演示 Swarms Cloud 的最新功能。第一个介绍 Auto Agent Builder：用一句自然语言任务描述生成完整的智能体团队，专属角色、系统提示词、模型选择和生成参数在几秒内自动完成。第二个讲解 Compare 功能：把同一个任务同时交给多个 AI 智能体运行，并将它们的回答并排展示，让模型和配置的选择变成直接对比，而非一次次的顺序试错。

一套完整的 Swarms Cloud 课程正在制作中，内容覆盖从基础到高级智能体工作流的全部环节。在此期间，Swarms Academy 上的 Swarms API 课程现已开放并提供认证，新注册 Swarms Cloud 的用户可获得 5 美元免费额度开始构建。

## Vault Mode 竞赛进入最后几天

![Vault Mode 竞赛](/vault_mode_competition.png)

Vault 代币化智能体竞赛本周进入冲刺阶段，公告发布时距离结束已不足五天。竞赛基于 Vault Mode 运行：这一发布机制将智能体的访问权限限定为该智能体代币的持有者。奖池共 2,000 美元，分配给排名前三的参赛作品。参赛方式很简单：启用 Vault Mode 发布一个代币化智能体，并出现在竞赛排行榜上。

## 错峰定价：夜间 API 代币成本减半

Swarms API 错峰定价已经上线：太平洋时间晚 8 点至早 6 点之间，Swarm Completions 的代币成本立减 50%，覆盖数千个模型，包括 Fable 和 GPT-5.6 Sol。对于可以安排到夜间窗口的工作负载（批处理、评估运行、定时智能体任务），这项折扣能把推理成本直接减半，且 API 接口无需任何改动。这也是平台上动态代币定价的一个早期生产实例：价格随需求变化，而非全天固定。

## 结语

本周从两个方向同时构建了代币化智能体的市场基础设施。Screener 为生态提供了一个内部的事实来源，基于链上数据实时呈现什么在发布、什么在上升、什么在交易。GMGN 集成则把同样的智能体带给了生态之外的交易者群体，借助他们已有的工具和习惯，预计将随之加深整个生态的流动性。

围绕这个核心，平台继续降低各个环节的门槛：在完整课程推出之前，视频教程先行演示 Auto Agent Builder 和 Compare 功能；错峰定价让夜间 API 成本减半；竞赛周期进入最后几天。而招聘的全面展开最能说明方向：市场基础设施、开发者教育、定价与分发，每一条线都在组建专门的团队。
