# Swarms 生态每周更新 [7 月 21-26 日]：Frenzy Hub、Marketplace 全新首页，以及 Swarms Cloud 上线 Gemini 3.6 Flash

过去一周，Swarms 技术栈的四个层面都有交付：代币化智能体市场、Marketplace 的发现体验、Marketplace 的平台工程，以及 Swarms Cloud 的模型覆盖。每一项发布都针对开发者从可运行的原型走向被他人使用并付费的产品时遇到的不同瓶颈。

这些更新贯穿两条主线。第一条是可读性。Frenzy Hub 与 Marketplace 新首页都把原本已经存在的数据放到创作者和买家可以据此行动的位置，随着已发布的智能体、提示词和工具数量增长，这一点愈发重要。第二条是生产可用性。Marketplace 更新日志记录了支付、搜索与性能方面近 200 项已上线的改动，而最新的 Gemini 系列模型登陆 Swarms Cloud，则为多智能体系统中 token 消耗密集的内层循环提供了成本更低的选择。

本文逐项介绍这些进展，说明其技术意义，并附上对应的完整公告链接。链接统一放在各章节的资源部分以及文末的汇总列表中。

## Frenzy Hub 把所有代币化智能体汇总到一个页面

![Swarms 上的 Frenzy Hub](/frenzy_mode_hub.png)

Frenzy Hub 是 Frenzy Mode 的专属主页。Frenzy Mode 是发布时的一项设置：启用后，创作者可在其智能体或提示词代币的整个生命周期内，获得每一笔买入和每一笔卖出的 1%。该 Hub 将所有 Frenzy 发布项汇总为单一视图：可筛选的行情筛选器、按创作者全部发布项合计市值排名的创作者排行榜、按市值排列的头部代币卡片，以及实时价格、交易量和交易者数量。在此之前，Frenzy 代币散落在注册表的筛选条件之后，只能逐个打开才能对比。把数据聚合在一处让市场在两个方向上都变得清晰：创作者可以将自己作品的真实需求与其他所有发布项对比衡量，买家则可以在下单前评估热度。创作者也可以直接在同一页面完成发布。🔥

## Swarms Marketplace 上线全新首页

![Swarms Marketplace 全新首页](https://pbs.twimg.com/media/HN13Dc6WsAAkF0f?format=jpg&name=medium)

Swarms Marketplace 在 swarms.world 上线了重新设计的首页。Marketplace 是整个生态的发布与分发层，是开发者把一个可用的智能体、提示词或工具推向付费用户的最短路径。目前社区已在其上发布超过 6,000 个条目，累计产生数千万级别的交易量。在这样的目录规模下，首页承担了大部分发现工作，因为它决定了新访客最先看到哪些作品，以及他们多快能找到与自己相关的内容。新版布局重新组织了这一入口，让浏览目录、了解 Marketplace 的功能定位、以及跳转到具体条目都从同一个界面出发。对创作者来说，首页上更好的展示位置会直接转化为其发布内容的分发量。

## 七周内上线近 200 项 Marketplace 更新

![Swarms Marketplace 六月与七月更新日志](/swarms_marketplace_changelog_june.png)

我们发布了一份更新日志，覆盖 6 月 1 日至 7 月 21 日期间 Swarms Marketplace 上线到生产环境的全部改动：七周内近 200 项更新，涉及发现体验、支付、创作者工具和性能。主要发布包括通过 Stripe 接入的法币支付、由智能体驱动的自然语言搜索、Marketplace 组合包、带有改进版产品页的社区点赞系统，以及带独特头像的创作者身份，另有数十项较小的修复与速度优化。公布完整日志而不仅仅是重点功能，能给开发者提供可用于规划的依据：它显示平台哪些部分正在活跃开发、记录现有集成下发生变化的行为，并确立可预期的发布节奏。该日志采用通俗语言撰写，每一条都说明改了什么以及在实际使用中意味着什么。

## Gemini 3.6 Flash 与最新 Gemini 模型在 Swarms Cloud 上线

![Swarms Cloud 上的 Gemini 模型](/gemini_banner_swarms.png)

Gemini 3.6 Flash 以及最新 Gemini 系列的其余型号（包括 3.5 Flash-Lite）现已在 Swarms Cloud 上可用，支持单智能体与多智能体工作负载。Google 表示，3.6 Flash 在相同成本下使用比 3.5 Flash 更少的 token 即可产出更高质量的结果，而 3.5 Flash-Lite 面向高频的日常任务。token 效率在多智能体系统中会被放大：一次运行可能涉及多个智能体、每个智能体多轮交互以及共享上下文，因此单次调用的节省会在整个 swarm 中成倍累积。为降低接入门槛，我们发布了一份开发者指南，覆盖 API 密钥配置、单智能体执行和多智能体编排，每一步都提供完整的 Python 与 cURL 示例。已有的 Swarms API 代码只需修改模型标识符即可切换到新模型。

## 总结

本周的发布沿两个方向推进了生态。Frenzy Hub 与 Marketplace 新首页改进了创作者分发作品、买家评估作品的界面，而这正是目录规模增长转化为使用量增长的环节。Marketplace 更新日志记录了这些界面之下的工程工作，从银行卡支付到智能体驱动的搜索，再到页面性能，为开发者提供了一份可靠的变更记录。

模型覆盖同步推进。把最新的 Gemini 模型加入 Swarms Cloud，降低了运行编排密集型负载的成本，配套指南也减少了在这些模型上把智能体投入生产所需的工作量。这四项更新共同指向同一个方向：让在 Swarms 上构建、部署、分发和变现生产级多智能体系统成为一件可行的事。
