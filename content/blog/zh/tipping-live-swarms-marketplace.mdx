# Swarms Marketplace 打赏功能正式上线

[Swarms Marketplace](https://swarms.world) 上许多最优秀的作品都是免费的。成千上万的智能体、提示词、工具和捆绑包，由创作者免费发布，让更多人可以使用。在此之前，想要感谢他们，你只能点赞或留下一条评价。

从今天起，你可以用真金白银来表达感谢。Marketplace 上的每一个免费商品，现在都可以显示 **Tip（打赏）** 按钮。任何觉得某个商品有用的人，都可以通过银行卡、USDC 或 SOL 给创作者打赏几美元，只需点几下，无需离开商品页。

## 为什么要做打赏

Marketplace 已经支持付费商品，可以通过 Stripe 刷卡购买，也可以在 Solana 上用加密货币购买。但很多创作者并不想把作品放在付费墙后面。他们选择免费发布，是为了获得更多用户、更多反馈和更好的口碑。免费，不应该等于没有回报。

打赏正好填补了这个空白：

- **对用户而言**，打赏是一种直接的方式，用来支持那些帮你节省大量时间的智能体和提示词的作者，让他们继续创作。
- **对创作者而言**，打赏让免费商品也能带来收入，而且不改变任何人的使用方式。没有内容被锁定，不打赏的用户体验也完全不变。
- **对智能体经济而言**，打赏奖励的是开放、慷慨的创作，而正是这些作品让 Marketplace 值得一逛。

打赏是一份谢意，而不是一次购买。它不会解锁任何内容，不会授予付费商品的访问权限，也不会增加账户余额。付费商品保留原有的购买流程，不会显示 Tip 按钮。

## 本次上线的内容

- **免费商品上的 Tip 按钮。** 只要创作者已开通收款，每个免费智能体、提示词、工具和捆绑包的侧边栏都会显示该按钮。
- **通过 Stripe 刷卡打赏。** Stripe 的支付表单直接在打赏窗口内加载，你全程不用离开商品页。
- **使用 USDC 或 SOL 打赏。** 连接 Solana 钱包，一笔交易即可把打赏直接转入创作者的钱包。
- **金额从 $1 到 $500。** 可以选择 $5、$10 或 $20，也可以输入自定义金额。
- **可选留言。** 最多 280 个字符，让创作者知道是什么帮到了你。
- **付款前金额一目了然。** 确认之前，打赏窗口会准确显示创作者最终能收到多少钱。

## 用户如何打赏

整个过程不到一分钟。

### 1. 打开免费商品，点击 Tip

在 [Marketplace](https://swarms.world) 中打开任意一个免费的智能体、提示词、工具或捆绑包。如果创作者已开通收款，侧边栏会显示 **Tips** 区域和 **Tip** 按钮。你需要先登录 swarms.world；未登录时点击 Tip，会先提示你登录。

### 2. 选择金额并添加留言

选择 **$5**、**$10** 或 **$20**，或输入 $1 到 $500 之间的任意金额。你还可以添加一条最多 280 个字符的留言，例如"感谢你做了这个！"。金额下方的 **Publisher receives（创作者实收）** 会显示创作者实际收到的金额。

### 3. 刷卡或用加密货币支付

如果创作者两种方式都已开通，窗口顶部会出现 **Card / Crypto** 切换；如果只开通了一种，窗口只显示那一种。

**刷卡支付。** 点击 **Continue to card payment**，Stripe 的安全支付表单会在打赏窗口内加载。在这里完成付款，你全程停留在商品页。银行卡信息直接发送给 Stripe，Swarms 永远看不到你的卡号。

**加密货币支付。** 连接 Phantom 或 Solflare 等 Solana 钱包，然后选择 **USDC** 或 **SOL**。你只需签署一笔交易，同时向创作者和 Swarms 付款。USDC 打赏金额与美元金额完全一致；SOL 按付款时的实时价格换算。你还需要支付少量 Solana 网络手续费。

### 4. 完成

你会看到 **Thanks for the tip**，打赏已在发送给创作者的路上。

如果 Solana 网络确认较慢，窗口会保留你的付款记录，并显示 **Finish tip** 按钮。点击它会登记你已经发出的那笔付款，绝不会重复扣款。

## 创作者如何收款

创作者可以只接受刷卡打赏、只接受加密货币打赏，或者两者都接受。设置只需几分钟，而且只需设置一次。

### 1. 发布免费商品

打赏面向的是可以免费使用的商品。[发布一个智能体、提示词、工具或捆绑包](https://swarms.world/launch)，并设置为免费。付费商品仍走正常的购买流程，不接受打赏。

### 2. 在商品页点击 Get Tips

当你查看自己的免费商品时，侧边栏显示的是 **Get Tips** 按钮，而不是 Tip。点击它即可开始设置刷卡打赏。你不能给自己的商品打赏。

### 3. 开通 Stripe 卖家账户，接收刷卡打赏

如果你还没有 Stripe 卖家账户，Get Tips 会带你前往账户中的 [卖家标签](https://swarms.world/platform/account?tab=seller)。请先在这里选择你的国家或地区，因为 Stripe 之后无法修改。随后，你将进入 Stripe 托管的入驻流程，填写身份和银行信息。如果你之前已经开始过，Get Tips 会直接带你回到 Stripe 继续完成。

Stripe 审核通过后，你所有免费商品上都会出现 Tip 按钮。刷卡打赏会进入你的 Stripe 余额，并按照 Stripe 的常规结算周期打到你的银行账户。

如果你已经在用银行卡销售付费商品，说明你的 Stripe 账户已经开通，你的免费商品可以直接接受刷卡打赏。

### 4. 连接钱包，接收加密货币打赏

如果还想接受 USDC 和 SOL 打赏，请在 [账户 → 账单](https://swarms.world/platform/account?tab=billing) 中连接你的 Solana 钱包。加密货币打赏会在打赏者签署的同一笔交易中直接转入该钱包，Swarms 从不托管这笔资金。

你可以只开通刷卡、只开通加密货币，或两者都开通。提供的方式越多，别人给你打赏就越方便。

## 费用

发布免费，打赏没有任何订阅费或上架费。Swarms 从每笔打赏中收取 10%，这 10% 从打赏金额中扣除，而不是额外加收。

刷卡打赏时，Stripe 的银行卡手续费（2.9% + 30 美分）也从打赏金额中扣除。加密货币打赏时，Solana 网络手续费由打赏者另行支付，因此创作者能拿到完整的 90%。

| 打赏金额 | 刷卡时创作者实收 | 加密货币时创作者实收 |
| -------- | ---------------- | -------------------- |
| $5.00    | $4.05            | $4.50                |
| $10.00   | $8.41            | $9.00                |
| $20.00   | $17.12           | $18.00               |
| $100.00  | $86.80           | $90.00               |

付款前，打赏窗口始终会显示准确金额，没有任何意外。

## 技术实现

**刷卡打赏**基于 Stripe Connect，也就是 Marketplace 刷卡销售所使用的同一套基础设施。每笔打赏都是一笔 destination charge：打赏者付款后，Stripe 把创作者的份额转入其关联账户，Swarms 的费用则作为平台手续费（application fee）在同一笔交易中收取。Stripe 支付表单嵌入在打赏窗口中运行，打赏记录来自 Stripe 的付款成功 webhook，因此只有 Stripe 确认付款后，打赏才会被记录。

**加密货币打赏**是一笔包含两次转账的 Solana 交易：90% 转给创作者的钱包，10% 转给平台。在记录打赏之前，服务器会在链上核验这笔交易，确认两笔转账都已到账且金额正确。每笔交易只能被记录一次，这也是 **Finish tip** 可以放心点击的原因。

无论通过哪种方式支付，服务器都会对每笔打赏进行校验：

- 商品必须存在且为免费商品。
- 你不能给自己的商品打赏。
- 创作者必须已开通对应的收款方式。
- 金额必须在 $1 到 $500 之间。
- 留言最多 280 个字符。

频繁重复的尝试会被限流。

## 常见问题

**谁可以打赏？**
任何已登录 swarms.world 的用户。

**哪些商品可以接受打赏？**
免费的智能体、提示词、工具和捆绑包，前提是创作者已开通刷卡打赏、加密货币打赏或两者。付费商品不会显示 Tip 按钮。

**打赏会解锁什么内容吗？**
不会。打赏只是一份谢意，不会授予付费商品的访问权限，也不会增加账户余额。

**每次可以打赏多少？**
每笔 $1 到 $500，可附带最多 280 个字符的留言。

**可以用哪些加密货币打赏？**
Solana 上的 USDC 和 SOL。

**Swarms 能看到我的卡号吗？**
不能。支付表单由 Stripe 渲染，你的银行卡信息直接发送给 Stripe。

**创作者什么时候能收到钱？**
刷卡打赏进入创作者的 Stripe 账户，并按 Stripe 的结算周期打到银行账户。加密货币打赏在打赏者签署的同一笔交易中直接到达创作者的钱包。

**接收打赏一定需要 Stripe 账户吗？**
接收刷卡打赏需要。接收加密货币打赏只需要连接 Solana 钱包。两者可以任选其一，也可以都开通。

**我可以给自己的商品打赏吗？**
不可以。在你自己的免费商品上，你看到的是 Get Tips 按钮，用于开通收款。

打赏功能今天已向 Swarms Marketplace 的所有用户开放。

- **用户：** 打开任何一个对你有帮助的免费商品，点击 **Tip**。
- **创作者：** 打开你的任一免费商品，点击 **Get Tips**，或在 [账户 → 账单](https://swarms.world/platform/account?tab=billing) 中连接钱包。
- **所有人：** 在 [swarms.world/tips](https://swarms.world/tips) 查看完整说明。

免费的作品，同样值得支持。现在，只需轻点一下。
