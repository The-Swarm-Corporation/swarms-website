# Vault Mode 代币化智能体竞赛正式开启：两周角逐 2,000 美元 SOL 奖池

新一届 [Swarms Marketplace](https://swarms.world) 竞赛现已开放。在接下来的两周里，发行启用 Vault Mode 的 AI 智能体，即可角逐以 SOL 支付的 2,000 美元奖池。竞赛窗口关闭时，交易量最高的三个 Vault Mode 智能体代币将瓜分奖金。参赛自动生效，排行榜实时更新，胜负由市场决定。

## Vault Mode 改变了什么

大多数智能体代币是纯金融性的：任何人都可以使用智能体，同时任何人也都可以交易它的代币，两者之间毫无关联。

Vault Mode 把二者连接了起来。它是[发行流程](https://swarms.world/launch?model=tokenized)代币化步骤中的一个开关，能把你的代币变成访问机制本身。启用之后，只有持有该智能体代币的人才能访问和使用这个智能体：在已连接钱包中持有至少 1 美元代币的访客可以进入，其他人则会看到一个带有内置购买组件的锁定页面。使用需求转化为买入压力，你的用户社区和持币者社区变成了同一群人。想了解完整机制，请阅读我们的 [Vault Mode 深度解析](https://swarms.world/blog/vault-mode-tokenized-agents)。

## 奖金与排名规则

竞赛结束时，交易量最高的三个 Vault Mode 智能体代币获胜：

- **第一名：1,000 美元 SOL**
- **第二名：700 美元 SOL**
- **第三名：300 美元 SOL**

排名依据自发行以来的总交易量：窗口期内的每一笔买入和卖出，以美元计价累加。交易量从原始链上交易中重建，而非滚动 24 小时数据，因此窗口初期的交易与最后一天的交易权重完全相同。[排行榜](https://swarms.world/competitions/vaulted-tokenized-agents)在竞赛开放期间持续刷新，倒计时归零那一刻屏幕上的最终榜单就是发放奖金的依据。

有两条规则值得提前了解。只有在窗口期内（UTC 时间 8 月 4 日零点至 8 月 19 日 02:00）发行且启用 Vault Mode 的智能体和提示词才有参赛资格，窗口期之外发行的一律不计入。此外，刷量交易、自买自卖或用同一批钱包循环交易来虚增交易量，都将被取消资格。奖金以 SOL 形式发放到获胜创作者账户所连接的钱包。

## 如何参赛

参赛只需几分钟：

1. **注册账号**：前往 [swarms.world/signup](https://swarms.world/signup)。
2. **发行一个 Vault Mode 代币化智能体**：在[发行页面](https://swarms.world/launch?model=tokenized)操作。发布前务必启用 Vault Mode，这是让你登上榜单的关键。
3. **追踪你的排名**：在[实时排行榜](https://swarms.world/competitions/vaulted-tokenized-agents)上关注你的位置并推动交易量：分享你的智能体，建设你的社区，让更多人持有它。

就这么简单。每一个符合条件的 Vault Mode 发行都会自动参赛。没有报名表，没有评审团，也没有参赛费用：Swarms 上的竞赛只发钱，从不收费。

## 从投机走向实用

智能体经济正在从投机转向实用。Vault Mode 赋予智能体代币一份真正的工作：它是产品的钥匙，是一种将创作者、用户和持币者围绕同一资产对齐的链上所有权模型。这场竞赛的意义，就是奖励那些正在验证这一模式的构建者。

截止时间是 UTC 时间 8 月 19 日 02:00。发行你的 Vault Mode 智能体，冲上排行榜，拿下 2,000 美元奖池中属于你的那一份。
